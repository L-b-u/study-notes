# 动态规划题型判断

动态规划题最难的通常不是循环，而是从题意中判断：

```text
这道题属于哪类 DP？
dp[i] 或 dp[i][j] 表示什么？
当前状态从哪些更小状态转移而来？
```

## 一、四类 DP 总览

| 类型 | 常见特征 | 常见状态 |
| --- | --- | --- |
| 网格 DP | 矩阵、路径、左上角到右下角 | dp[i][j] |
| 背包 DP | 选择物品、凑金额、容量、总和、价值 | dp[capacity] |
| 序列 DP | 数组中的最长、最大、最少、当前位置结尾 | dp[i] |
| 字符串 DP | 匹配、拆分、公共子序列、编辑 | dp[i] 或 dp[i][j] |

题型可以重叠：

```text
单词拆分 = 字符串问题 + 一维 DP
最长公共子序列 = 字符串问题 + 二维 DP
零钱兑换 = 背包问题 + 一维 DP
```

## 二、网格 DP

### 题目特征

看到下面的词，优先考虑网格 DP：

```text
网格、矩阵、左上角、右下角、向右、向下、路径
```

典型题：62《不同路径》、64《最小路径和》。

### 常见状态

```text
dp[i][j]：走到网格坐标 (i, j) 的答案
```

当前格子通常从上方或左方到达：

```text
不同路径：dp[i][j] = dp[i-1][j] + dp[i][j-1]
最小路径和：min(上方, 左方) + grid[i][j]
```

需要重点检查第一行、第一列和起点初始化。

## 三、背包 DP

### 题目特征

看到下面的词，优先考虑背包 DP：

```text
选择若干个、凑出目标和、容量、金额、最大价值、
每个物品只能使用一次、物品可以重复使用
```

先问自己：

```text
是不是要从一堆物品中选择一些东西？
```

### 0/1 背包和完全背包

| 类型 | 使用次数 | 容量遍历 |
| --- | --- | --- |
| 0/1 背包 | 每个物品一次 | 倒序 |
| 完全背包 | 物品可以重复 | 正序 |

记忆：

```text
只能用一次 → 倒序
可以重复用 → 正序
```

### 典型状态

《分割等和子集》：

```text
dp[i]：能否凑出总和 i
```

《零钱兑换》：

```text
dp[i]：凑出金额 i 所需的最少硬币数
```

《零钱兑换 II》：

```text
dp[i]：凑出金额 i 的组合数
```

求组合数时，硬币放外层，避免将不同顺序重复计算。

## 四、序列 DP

### 题目特征

```text
数组、序列、最长、最大、最少、以当前位置结尾
```

典型题：300《最长递增子序列》、53《最大子数组和》、198《打家劫舍》。

### 常见状态

《最长递增子序列》：

```text
dp[i]：以 nums[i] 结尾的最长递增子序列长度
```

如果 `nums[j] < nums[i]`：

```python
dp[i] = max(dp[i], dp[j] + 1)
```

《打家劫舍》：

```text
dp[i]：前 i 间房能偷到的最大金额
```

遇到序列题要确认：`dp[i]` 表示前 i 个元素，还是以第 i 个元素结尾。

## 五、字符串 DP

### 题目特征

```text
两个字符串、公共子序列、编辑距离、匹配、前缀、拆分、回文
```

《单词拆分》：

```text
dp[i]：s 的前 i 个字符能否由字典单词拼出
```

《最长公共子序列》：

```text
dp[i][j]：两个字符串前 i、前 j 个字符的最长公共子序列长度
```

转移口诀：

```text
当前字符相等：左上角 + 1
当前字符不等：上方和左方取最大
```

注意区分：

```text
子序列：不要求连续，但相对顺序不能改变
子串：必须连续
```

## 六、统一判断流程

遇到一道不会的 DP 题，按下面顺序判断：

1. 有二维网格、路径和移动方向吗？有则优先考虑网格 DP。
2. 是从物品中选择来凑金额、容量或总和吗？是则考虑背包 DP。
3. 是数组中的最长、最大、最少问题吗？是则考虑序列 DP。
4. 是字符串匹配、拆分、公共关系或编辑问题吗？是则考虑字符串 DP。
5. 写一句状态定义：`dp[i]` 或 `dp[i][j]` 到底表示什么。
6. 思考当前答案的最后一步来自哪些更小状态。
7. 最后检查初始化、遍历方向和返回位置。

## 八、刷题方法

遇到不会的题，不要立刻背代码：

1. 先判断大类。
2. 写出状态定义。
3. 想当前状态的最后一步。
4. 写自然语言转移，再翻译成代码。
5. 检查边界和遍历方向。
6. 卡住约 15 到 20 分钟后再看提示。
7. 看懂后合上答案，重新独立写一遍。

现在“看代码能看懂，但自己想不到”是正常阶段。这说明你已经能识别状态转移，下一步要训练的是从题意主动定义状态。

## 一句话总结

```text
判断 DP 题型只是第一步，真正决定能否做出来的是：
先写清 dp 表示什么，再想当前答案如何从更小状态转移而来。
```
