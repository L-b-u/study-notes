# 滑动窗口

待通过题目逐步补充。

## 什么时候想到它

题目涉及数组或字符串的连续子数组、子串、区间，并且需要在 O(n) 时间内寻找满足条件的最长、最短或计数结果时，优先考虑滑动窗口。

## 常见窗口操作

- 右指针扩张窗口，纳入新元素。
- 条件不满足时，左指针收缩窗口，移除旧元素。
- 使用哈希表维护窗口内元素的次数或状态。

## 模板：无重复字符的最长子串

```python
chars = set()
left = 0
best = 0

for right in range(len(s)):
    while s[right] in chars:
        chars.remove(s[left])
        left += 1

    chars.add(s[right])
    best = max(best, right - left + 1)

return best
```

### 指针职责

- `right`：逐个读取新字符，尝试扩张窗口。
- `left`：当窗口中出现重复字符时，逐步移除窗口左侧字符，直到窗口重新合法。
- `chars`：记录窗口中当前有哪些字符。
- `best`：记录历史上最长的合法窗口长度。

### 为什么用 while

出现重复时，左边界可能需要移动多次。例如窗口为 `"ab"`，读到第二个 `"b"`：先移除 `a` 后仍有旧 `b`，还要继续移除旧 `b`，才能加入当前 `b`。因此必须用 `while`，不能只用 `if`。

## 模板：和至少为 target 的最短子数组

适用于数组元素都为正整数，并且需要寻找元素和满足条件的最短连续子数组。

```python
left = 0
window_sum = 0
best = float("inf")

for right in range(len(nums)):
    window_sum += nums[right]

    while window_sum >= target:
        best = min(best, right - left + 1)
        window_sum -= nums[left]
        left += 1

return 0 if best == float("inf") else best
```

### 指针与变量职责

- `right`：向右扩张窗口，将 `nums[right]` 纳入窗口。
- `window_sum`：维护当前窗口所有元素的和。
- `left`：窗口和达到 `target` 后，从左侧收缩窗口。
- `best`：记录历史上满足条件的最短窗口长度。

### 为什么先扩张、再收缩

右指针加入新元素后，窗口才可能第一次满足 `window_sum >= target`。一旦满足，当前窗口是一个候选答案；随后不断移除左侧元素，尝试得到更短的候选窗口。因此每次进入 `while` 时，都应先更新 `best`，再移动 `left`。

### 为什么元素必须为正整数

移除左侧正整数后，`window_sum` 一定变小。于是当窗口和小于 `target` 时，继续收缩不可能重新合法，只能移动 `right` 扩张窗口。这使得左右指针都只会向右移动，整体时间复杂度为 O(n)。若数组允许负数，这个性质不成立，不能直接使用此模板。

## 模板：固定长度的异位词窗口

适用于寻找字符串中所有与给定字符串 `p` 互为字母异位词的连续子串。异位词字符出现次数相同，因此候选窗口长度固定为 `len(p)`。

```python
left = 0
result = []
need = {}
window = {}

for char in p:
    need[char] = need.get(char, 0) + 1

for right in range(len(s)):
    right_char = s[right]
    window[right_char] = window.get(right_char, 0) + 1

    while right - left + 1 > len(p):
        left_char = s[left]
        window[left_char] -= 1
        if window[left_char] == 0:
            del window[left_char]
        left += 1

    if window == need:
        result.append(left)

return result
```

### 为什么窗口长度固定

任何与 `p` 互为异位词的子串，长度都必须等于 `len(p)`。右侧加入一个字符后，如果窗口过长，就只移出一个或多个左侧字符，直到长度恢复为 `len(p)`；随后比较两个计数字典是否相等。

### 计数字典的注意点

`need` 记录 `p` 中每个字符的数量，`window` 记录当前窗口的数量。左侧字符计数减为 `0` 时必须删除该键，否则 `{"c": 0, "a": 1, "b": 1}` 与 `{"a": 1, "b": 1}` 并不相等，会漏掉答案。

### 同模板：判断是否存在异位词窗口

若题目只要求判断是否存在一个异位词窗口，窗口移动和计数方式完全相同。唯一差别是两个字典相等时直接返回 `True`；遍历结束仍未找到则返回 `False`。

```python
if window == need:
    return True

return False
```

## 模板：至多 K 种元素的最长子数组

适用于连续子数组或子串中最多包含 K 种不同元素，并要求最长长度的题目。LeetCode 904 是 K 为 2 的特例。

```python
left = 0
window = {}
best = 0

for right in range(len(items)):
    item = items[right]
    window[item] = window.get(item, 0) + 1

    while len(window) > k:
        left_item = items[left]
        window[left_item] -= 1
        if window[left_item] == 0:
            del window[left_item]
        left += 1

    best = max(best, right - left + 1)

return best
```

### 关键规律

窗口中不同元素的数量超过 K 时，窗口不合法，必须持续从左侧收缩，直到重新合法。每轮收缩完成后，窗口都满足“至多 K 种”的要求，此时用 `right - left + 1` 更新全局最长长度；不能在窗口恰好有 K 种元素时提前返回，因为后面可能出现更长的合法窗口。

## 模板：至多 K 个不满足项的最长子数组

适用于窗口中允许最多 K 个特定元素或不满足项，并要求最长连续子数组的题目。LeetCode 1004 中允许把最多 K 个 `0` 翻成 `1`，因此窗口内最多允许 K 个 `0`。

```python
left = 0
zero_count = 0
best = 0

for right in range(len(nums)):
    if nums[right] == 0:
        zero_count += 1

    while zero_count > k:
        if nums[left] == 0:
            zero_count -= 1
        left += 1

    best = max(best, right - left + 1)

return best
```

### 判断条件

判断的不是窗口里有多少种元素，而是窗口内“需要消耗操作次数”的元素数量是否超过预算。第 1004 题中每个 `0` 需要一次翻转，因此条件是 `zero_count > k`；超限便收缩，重新合法后更新最长长度。

## 模板：固定长度窗口中的目标元素数量

适用于窗口长度固定为 K，只需要统计某类元素数量并求最大值的题目。LeetCode 1456 中，目标元素是元音字母。

```python
left = 0
vowels = {"a", "e", "i", "o", "u"}
vowel_count = 0
best = 0

for right in range(len(s)):
    if s[right] in vowels:
        vowel_count += 1

    while right - left + 1 > k:
        if s[left] in vowels:
            vowel_count -= 1
        left += 1

    if right - left + 1 == k:
        best = max(best, vowel_count)

return best
```

### 固定窗口口诀

右边进一个；长度超过 K，左边出一个；长度等于 K，更新答案。只维护题目关心的指标即可，本题只需维护元音数量，无须为所有字符建立计数字典。
