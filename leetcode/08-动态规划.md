# 动态规划

## 入门思路

动态规划通常把大问题拆成规模更小、且会重复出现的子问题，并保存子问题答案。入门题可以按四步思考：

1. 定义状态：`dp[i]` 表示什么。
2. 推导转移：当前状态最后一步来自哪些更小状态。
3. 确定初始值：最小规模问题的答案是什么。
4. 确定遍历顺序：计算当前状态前，依赖的状态必须已经算出。

## 模板：爬楼梯

每次可以走 1 阶或 2 阶。到达第 `i` 阶的最后一步，要么从 `i - 1` 走 1 阶，要么从 `i - 2` 走 2 阶，因此：

```python
if n <= 2:
    return n

dp = [0] * (n + 1)
dp[1] = 1
dp[2] = 2

for i in range(3, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]

return dp[n]
```

由于当前状态只依赖前两个状态，也可以压缩成两个变量，空间复杂度降为 O(1)。

## 模板：使用最小花费爬楼梯

定义 `dp[i]` 为到达第 `i` 阶位置所需的最小花费，其中 `i = n` 表示已经到达楼顶。题目允许从第 `0` 阶或第 `1` 阶开始，因此 `dp[0] = dp[1] = 0`。

到达第 `i` 阶有两种方式：从 `i - 1` 走一步并支付 `cost[i - 1]`，或从 `i - 2` 走两步并支付 `cost[i - 2]`。

```python
n = len(cost)
dp = [0] * (n + 1)

dp[0] = 0
dp[1] = 0

for i in range(2, n + 1):
    dp[i] = min(
        dp[i - 1] + cost[i - 1],
        dp[i - 2] + cost[i - 2],
    )

return dp[n]
```

这类题的关键是先明确状态代表“到达哪一个位置”，再决定每一步支付哪个位置的费用。
