# 栈与队列

## 栈的特点

栈遵循后进先出（LIFO）：最后入栈的元素最先出栈。Python 中通常使用列表模拟栈：

```python
stack = []
stack.append(value)  # 入栈
value = stack.pop()  # 出栈并返回栈顶
top = stack[-1]      # 查看栈顶，不移除
```

访问栈顶前要确认栈不为空，否则会触发下标错误。

## 模板：括号匹配

遇到左括号入栈；遇到右括号时，必须检查栈非空且栈顶是对应的左括号，匹配后再出栈。遍历结束时栈也必须为空。

```python
pairs = {
    ")": "(",
    "]": "[",
    "}": "{",
}
stack = []

for char in s:
    if char in "([{":
        stack.append(char)
    else:
        if not stack or stack[-1] != pairs[char]:
            return False
        stack.pop()

return len(stack) == 0
```

## 复杂度

- 时间复杂度：O(n)。每个字符最多入栈、出栈一次。
- 空间复杂度：O(n)。最坏情况下所有字符都是左括号。

## 模板：辅助栈维护最小值

当栈需要在 `O(1)` 时间内获取当前最小值时，使用一个与主栈同步变化的最小栈。最小栈每一层保存“截至当前层的最小值”。

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, value):
        self.stack.append(value)
        if self.min_stack:
            current_min = min(value, self.min_stack[-1])
        else:
            current_min = value
        self.min_stack.append(current_min)

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

### 同步不变量

两个栈始终等长。主栈保存真实元素；最小栈第 `i` 层保存主栈前 `i + 1` 个元素中的最小值。因此入栈、出栈必须同时操作两个栈，`getMin()` 直接查看 `min_stack[-1]`。

## 模板：两个栈实现队列

队列遵循先进先出（FIFO），栈遵循后进先出（LIFO）。使用入栈 `in_stack` 和出栈 `out_stack`：新元素只进入 `in_stack`；取队头前，当 `out_stack` 为空时才将 `in_stack` 所有元素逐个弹出并压入 `out_stack`。

```python
class MyQueue:

    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def _transfer(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    def pop(self):
        self._transfer()
        return self.out_stack.pop()

    def peek(self):
        self._transfer()
        return self.out_stack[-1]

    def empty(self):
        return not self.in_stack and not self.out_stack
```

### 为什么延迟转移

假设 `in_stack = [1, 2, 3]`，转移后 `out_stack = [3, 2, 1]`，栈顶 `1` 就是最早入队的元素。只有 `out_stack` 为空时才能转移；若其中仍有元素再次转移，新元素会跑到旧元素前面，破坏队列顺序。每个元素最多进入、离开两个栈各一次，因此所有操作的均摊时间复杂度为 O(1)。
