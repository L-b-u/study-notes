# 二分查找

## 什么时候想到它

当数组有序，并且题目要求查找目标值、边界或满足单调条件的位置时，可以考虑二分查找。每次比较中间位置后，都能排除一半候选范围。

## 基础模板：查找目标值

适用于在升序数组中查找目标值的下标，找不到时返回 `-1`。

```python
left = 0
right = len(nums) - 1

while left <= right:
    middle = (left + right) // 2

    if nums[middle] == target:
        return middle
    elif nums[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

return -1
```

### 区间与指针职责

- 使用闭区间 `[left, right]`，所以初始 `right = len(nums) - 1`。
- 只要 `left <= right`，区间中就可能还有未检查的元素。
- 中间值太小，目标只能在右侧，更新 `left = middle + 1`。
- 中间值太大，目标只能在左侧，更新 `right = middle - 1`。
- 每次更新范围后都要重新计算 `middle`。

## 复杂度

- 时间复杂度：O(log n)。每轮排除约一半元素。
- 空间复杂度：O(1)。只使用固定数量的指针变量。

## 变体：搜索插入位置

仍使用闭区间二分模板。若目标不存在，循环结束时 `left` 会停在第一个大于等于 `target` 的位置，因此它就是插入位置。

```python
if nums[middle] == target:
    return middle
elif nums[middle] < target:
    left = middle + 1
else:
    right = middle - 1

return left
```

这个结论也覆盖两端边界：目标小于所有元素时返回 `0`，目标大于所有元素时返回 `len(nums)`，空数组时也返回 `0`。

## 变体：二分答案并寻找最大合法值

有些题目没有给出有序数组，而是要求寻找一个满足单调条件的最大值或最小值。这时可以直接在答案范围上二分。

以整数平方根为例，判断条件是 `middle * middle <= x`：

```python
left = 0
right = x
best = 0

while left <= right:
    middle = left + (right - left) // 2

    if middle * middle <= x:
        best = middle
        left = middle + 1
    else:
        right = middle - 1

return best
```

### 判断方向

- 条件成立：`middle` 是合法答案，记录它，并向右尝试更大的合法值。
- 条件不成立：`middle` 太大，右侧的值也不可能合法，向左收缩。

## 常见边界

- 空数组：初始 `left > right`，直接返回 `-1`。
- 目标在第一个或最后一个位置：仍需保留闭区间两端的检查。
- 目标不存在：指针交错后退出循环，返回 `-1`。
