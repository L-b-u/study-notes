# 二分查找

## 什么时候想到它

当数组有序，并且题目要求查找目标值、边界或满足单调条件的位置时，可以考虑二分查找。每次比较中间位置后，都能排除一半候选范围。

## 基础模板：查找目标值

适用于在升序数组中查找目标值的下标，找不到时返回 `-1`。

```python
left = 0
right = len(nums) - 1

while left <= right:
    middle = (left + right) // 2

    if nums[middle] == target:
        return middle
    elif nums[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

return -1
```

### 区间与指针职责

- 使用闭区间 `[left, right]`，所以初始 `right = len(nums) - 1`。
- 只要 `left <= right`，区间中就可能还有未检查的元素。
- 中间值太小，目标只能在右侧，更新 `left = middle + 1`。
- 中间值太大，目标只能在左侧，更新 `right = middle - 1`。
- 每次更新范围后都要重新计算 `middle`。

## 复杂度

- 时间复杂度：O(log n)。每轮排除约一半元素。
- 空间复杂度：O(1)。只使用固定数量的指针变量。

## 常见边界

- 空数组：初始 `left > right`，直接返回 `-1`。
- 目标在第一个或最后一个位置：仍需保留闭区间两端的检查。
- 目标不存在：指针交错后退出循环，返回 `-1`。
