# 链表

## 链表节点

单链表节点通常包含当前值和指向下一个节点的 `next` 指针：

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

## 模板：迭代反转链表

使用 `prev` 和 `cur` 两个指针，将每个节点的 `next` 指向前一个节点。

```python
prev = None
cur = head

while cur:
    next_node = cur.next  # 先保存后继节点
    cur.next = prev
    prev = cur
    cur = next_node

return prev
```

### 指针顺序

必须先保存 `cur.next`，再修改 `cur.next`。否则原本指向后面链表的指针会丢失，无法继续遍历。循环结束时，`cur` 为 `None`，`prev` 指向新的头节点。

## 复杂度

- 时间复杂度：O(n)。每个节点处理一次。
- 空间复杂度：O(1)。只使用固定数量的指针。

## 模板：合并两个有序链表

使用一个独立的虚拟头节点 `dummy` 作为结果链表的占位起点，再用 `tail` 指向结果链表当前尾部。每次把两个链表当前节点中较小的一个接到 `tail` 后面。

```python
dummy = ListNode(0)
tail = dummy

while list1 and list2:
    if list1.val <= list2.val:
        tail.next = list1
        list1 = list1.next
    else:
        tail.next = list2
        list2 = list2.next
    tail = tail.next

tail.next = list1 if list1 else list2
return dummy.next
```

`dummy` 不属于任意一个输入链表，只是为了统一处理结果链表的第一个节点；真正的头节点是 `dummy.next`。

## 模板：快慢指针判断环

慢指针每次走一步，快指针每次走两步。若链表有环，快指针最终会在环内追上慢指针；若无环，快指针会先到达 `None`。

```python
slow = fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next

    if slow == fast:
        return True

return False
```

判断相遇要放在指针移动之后，否则两个指针初始化时都指向 `head`，会把所有非空链表误判为有环。

## 模板：删除倒数第 N 个节点

使用虚拟头节点和快慢指针。让 `fast` 先从 `dummy` 前进 `n` 步，再让两个指针同步前进；当 `fast` 到达尾节点时，`slow` 正好位于待删除节点的前一个节点。

```python
dummy = ListNode(0)
dummy.next = head
fast = slow = dummy

for _ in range(n):
    fast = fast.next

while fast.next:
    fast = fast.next
    slow = slow.next

slow.next = slow.next.next
return dummy.next
```

`dummy` 让删除原头节点时也能使用同一套逻辑。题目保证 `n` 有效，因此 `slow.next` 一定是要删除的节点。
