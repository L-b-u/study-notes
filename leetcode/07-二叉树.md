# 二叉树

## 二叉树节点

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

## 模板：前序遍历

前序遍历顺序是“根、左、右”。可以用递归，也可以用显式栈模拟递归。

### 递归写法

```python
result = []

def dfs(node):
    if not node:
        return
    result.append(node.val)
    dfs(node.left)
    dfs(node.right)

dfs(root)
return result
```

### 迭代写法

```python
result = []
if not root:
    return result

stack = [root]
while stack:
    node = stack.pop()
    result.append(node.val)

    # 右子树先入栈，左子树后入栈，左子树才能先出栈
    if node.right:
        stack.append(node.right)
    if node.left:
        stack.append(node.left)

return result
```

栈遵循后进先出，因此为了得到“根、左、右”，入栈顺序必须是右、左。迭代写法不受 Python 递归深度限制。

## 复杂度

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，其中 h 是树高；最坏情况下为 O(n)。

## 模板：递归计算最大深度

空树深度为 `0`；非空树深度为左右子树最大深度加上当前根节点这一层。

```python
def maxDepth(root):
    if not root:
        return 0

    left_depth = maxDepth(root.left)
    right_depth = maxDepth(root.right)
    return max(left_depth, right_depth) + 1
```

递归调用的返回值表示对应子树的深度。递归深度为 O(h)，极端倾斜的树可能触及 Python 递归深度限制；也可以使用层序遍历迭代求层数。

## 模板：翻转二叉树

对每个节点交换左右子树，再递归处理交换后的两个子树。

```python
def invertTree(root):
    if not root:
        return None

    root.left, root.right = root.right, root.left
    invertTree(root.left)
    invertTree(root.right)
    return root
```

交换后再递归时，`root.left` 和 `root.right` 已经是交换后的子树，继续处理即可。也可以先递归保存结果再交换，核心都是每个节点只交换一次。

## 模板：层序遍历

层序遍历使用队列，按层从上到下、每层从左到右访问节点。每层开始时先固定队列长度，恰好处理当前层的节点；新加入队列的孩子留到下一轮。

```python
from collections import deque

result = []
if not root:
    return result

queue = deque([root])
while queue:
    level = []

    for _ in range(len(queue)):
        node = queue.popleft()
        level.append(node.val)

        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)

    result.append(level)

return result
```

使用 `deque.popleft()` 以 O(1) 时间从队头取节点；不要在 Python 列表上反复 `pop(0)`，那会移动其余元素。

## 模板：递归判断对称二叉树

将问题拆为“两个节点是否互为镜像”。节点值相同后，左节点的左子树必须与右节点的右子树镜像，左节点的右子树必须与右节点的左子树镜像。

```python
def isSymmetric(root):
    if not root:
        return True

    def mirror(a, b):
        if not a and not b:
            return True
        if not a or not b:
            return False
        if a.val != b.val:
            return False

        return mirror(a.left, b.right) and mirror(a.right, b.left)

    return mirror(root.left, root.right)
```

迭代法可用队列保存待比较的节点对 `(a, b)`，每次把 `(a.left, b.right)` 和 `(a.right, b.left)` 加入队列。递归更简洁，迭代法可避免极深树的递归限制。
