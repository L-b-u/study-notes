# 二叉树

## 二叉树节点

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

## 模板：前序遍历

前序遍历顺序是“根、左、右”。可以用递归，也可以用显式栈模拟递归。

### 递归写法

```python
result = []

def dfs(node):
    if not node:
        return
    result.append(node.val)
    dfs(node.left)
    dfs(node.right)

dfs(root)
return result
```

### 迭代写法

```python
result = []
if not root:
    return result

stack = [root]
while stack:
    node = stack.pop()
    result.append(node.val)

    # 右子树先入栈，左子树后入栈，左子树才能先出栈
    if node.right:
        stack.append(node.right)
    if node.left:
        stack.append(node.left)

return result
```

栈遵循后进先出，因此为了得到“根、左、右”，入栈顺序必须是右、左。迭代写法不受 Python 递归深度限制。

## 复杂度

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，其中 h 是树高；最坏情况下为 O(n)。
