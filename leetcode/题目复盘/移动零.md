# 移动零

## 题意

将数组中的所有零移动到末尾，同时保持非零元素的相对顺序；要求原地修改数组。

## 我的思路

用同向双指针：`right` 遍历全部元素，`left` 指向下一个非零元素应该放入的位置。遇到非零元素时，将它交换到 `left`，然后 `left` 右移。

## 标准模板

```python
left = 0

for right in range(len(nums)):
    if nums[right] != 0:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
```

## 踩坑点

- 题目要求原地修改，因此不需要 `return nums`。
- 当 `left == right` 时，交换自身不影响结果。
- `left` 只在非零元素归位后右移。
