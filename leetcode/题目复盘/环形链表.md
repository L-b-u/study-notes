# 环形链表

LeetCode 141。

## 题意

给定一个链表的头节点，判断链表中是否存在环。环表示某个节点的 `next` 指针重新指向链表中之前出现过的节点。

## 我的思路

使用 Floyd 快慢指针算法。

- `slow` 每次移动一个节点。
- `fast` 每次移动两个节点。
- 如果没有环，`fast` 会先到达 `None`。
- 如果有环，两个指针都会进入环，`fast` 速度更快，最终一定会追上 `slow`。

## 标准模板

```python
slow = fast = head

while fast and fast.next:
    slow = slow.next
    fast = fast.next.next

    if slow == fast:
        return True

return False
```

## 复杂度

- 时间复杂度：O(n)。无环时遍历链表；有环时快慢指针在环内相遇。
- 空间复杂度：O(1)。只使用两个指针。

## 踩坑点

- 循环条件要检查 `fast` 和 `fast.next`，因为快指针每次走两步。
- 快指针必须写成 `fast = fast.next.next`，不能基于 `slow` 移动。
- 指针移动后再判断相等；初始化时 `slow` 和 `fast` 都指向 `head`，不能立刻判断。
- 空链表和单节点无环链表都会返回 `False`。
