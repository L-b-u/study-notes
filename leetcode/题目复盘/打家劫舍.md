# 打家劫舍

LeetCode 198。

## 题意

沿街有一排房屋，每间房里有一定金额。相邻的两间房不能在同一晚上偷，返回不触发报警时能够偷到的最大金额。

## 我的思路

定义 `dp[i]` 为前 `i` 间房能够偷到的最大金额。

- 不偷第 `i` 间，最大金额是 `dp[i - 1]`。
- 偷第 `i` 间，就不能偷第 `i - 1` 间，最大金额是 `dp[i - 2] + nums[i - 1]`。
- 两种选择取最大值，得到 `dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1])`。

## 标准模板

```python
def rob(nums):
    n = len(nums)
    if n == 0:
        return 0
    if n == 1:
        return nums[0]

    dp = [0] * (n + 1)
    dp[1] = nums[0]
    dp[2] = max(nums[0], nums[1])

    for i in range(3, n + 1):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1])

    return dp[n]
```

也可以只保存前两个状态：

```python
prev2, prev1 = 0, 0
for money in nums:
    prev2, prev1 = prev1, max(prev1, prev2 + money)
return prev1
```

## 复杂度

- 数组写法时间复杂度 O(n)，空间复杂度 O(n)。
- 状态压缩写法时间复杂度 O(n)，空间复杂度 O(1)。

## 踩坑点

- `dp[i]` 表示前 `i` 间房，不是下标为 `i` 的房子。
- `nums[i - 1]` 与 `dp[i]` 的下标不同，循环中要注意偏移。
- 不能把相邻两间房的金额同时加入。
- 空数组和只有一间房时，需要单独处理。
