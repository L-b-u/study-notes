# 无重复字符的最长子串

LeetCode 3。

## 题意

给定字符串 `s`，返回其中不含重复字符的最长连续子串长度。

## 我的思路

子串要求连续，使用滑动窗口。

- `right` 依次读取每个字符，试图扩张窗口。
- 用集合保存当前窗口里的字符。
- 如果当前字符已在集合中，从左侧持续移除字符、移动 `left`，直到当前字符不重复。
- 加入当前字符后，用窗口长度 `right - left + 1` 更新最大长度。

## 标准模板

```python
chars = set()
left = 0
best = 0

for right in range(len(s)):
    while s[right] in chars:
        chars.remove(s[left])
        left += 1

    chars.add(s[right])
    best = max(best, right - left + 1)

return best
```

## 复杂度

- 时间复杂度：O(n)。每个字符最多加入和移出集合一次。
- 空间复杂度：O(min(n, 字符集大小))。

## 踩坑点

- 子串必须连续，不能直接跳过当前的重复字符。
- 重复时使用 `while`，不是 `if`。
- 当前窗口长度是 `right - left + 1`。
