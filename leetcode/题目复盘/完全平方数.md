# 完全平方数

LeetCode 279。

## 题意

给定正整数 `n`，返回和为 `n` 的完全平方数的最少数量。

例如：

```text
12 = 4 + 4 + 4
```

所以 `12` 最少需要 `3` 个完全平方数。

## 我的思路

这道题可以看成完全背包问题：

```text
物品：1、4、9、16、...
容量：n
目标：凑出 n 所需的最少物品数量
```

完全平方数可以重复使用，例如 `12` 可以重复使用 `4` 三次。

## 状态定义

```text
dp[i]：凑出数字 i 所需的最少完全平方数个数
```

初始化：

```python
dp = [float("inf")] * (n + 1)
dp[0] = 0
```

`dp[0] = 0` 表示凑出数字 `0` 不需要任何平方数；其他状态初始化为无穷大，表示暂时不可达。

## 状态转移

如果当前选择完全平方数 `square`：

```text
先凑出 i - square
再加上一个 square
```

因此：

```python
dp[i] = min(dp[i], dp[i - square] + 1)
```

- `dp[i]`：不使用当前平方数，保留原来的方案。
- `dp[i - square] + 1`：使用一个当前平方数。

## 标准模板

```python
def numSquares(n):
    # dp[i]：凑出数字 i 所需的最少完全平方数个数
    dp = [float("inf")] * (n + 1)
    dp[0] = 0

    # 生成不超过 n 的所有完全平方数
    squares = []
    k = 1
    while k * k <= n:
        squares.append(k * k)
        k += 1

    # 完全背包：平方数可以重复使用
    for square in squares:
        for i in range(square, n + 1):
            dp[i] = min(dp[i], dp[i - square] + 1)

    return dp[n]
```

## 为什么金额正序遍历

因为完全平方数可以重复使用，所以内层金额必须从小到大遍历：

```python
for i in range(square, n + 1):
```

例如处理 `square = 4` 时：

```text
dp[4] 可以使用一个 4
dp[8] 可以在 dp[4] 的基础上再使用一个 4
dp[12] 可以在 dp[8] 的基础上再使用一个 4
```

这样就能得到：

```text
12 = 4 + 4 + 4
```

这和《零钱兑换》中的完全背包逻辑相同。

## 示例

```python
n = 12
```

不超过 `12` 的平方数是：

```text
1、4、9
```

最优拆分为：

```text
12 = 4 + 4 + 4
```

所以返回 `3`。

再例如：

```python
n = 13
```

可以拆分为：

```text
13 = 9 + 4
```

因此返回 `2`。

## 和零钱兑换的对应关系

两道题都属于完全背包，区别只是物品集合和目标：

```text
零钱兑换：物品是题目给出的 coins，求最少硬币数
完全平方数：物品是 1、4、9、16...，求最少平方数个数
```

状态转移形式完全一致：

```python
dp[i] = min(dp[i], dp[i - item] + 1)
```

## 复杂度

- 完全平方数的数量是 O(√n)。
- 时间复杂度：O(n√n)。
- 空间复杂度：O(n)，另外保存平方数列表需要 O(√n) 空间。

## 踩坑点

- `dp[i]` 表示凑出数字 `i` 的最少平方数个数，不是平方数本身。
- `dp[0]` 必须初始化为 `0`。
- 其他状态要初始化为无穷大，不能初始化为 `0`。
- 平方数可以重复使用，所以金额要正序遍历。
- 平方数列表只需要生成不超过 `n` 的数。
- 由于 `1` 本身是完全平方数，所以任意正整数都一定可以凑出，不需要返回 `-1`。
