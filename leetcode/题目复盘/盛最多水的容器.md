# 盛最多水的容器

LeetCode 11。

## 题意

给定非负整数数组 `height`，每个元素代表一条竖线高度。选择两条线与横轴形成容器，返回能够容纳的最大水量。

```text
面积 = (right - left) * min(height[left], height[right])
```

## 我的思路

使用相向双指针。

- `left` 从左端开始，`right` 从右端开始。
- 每轮先计算当前面积，并更新最大值。
- 每轮移动较短的边界：移动长板只会缩小宽度，且短板高度不变，面积无法变大。

## 标准模板

```python
left = 0
right = len(height) - 1
best = 0

while left < right:
    width = right - left
    container_height = min(height[left], height[right])
    best = max(best, width * container_height)

    if height[left] < height[right]:
        left += 1
    else:
        right -= 1

return best
```

## 复杂度

- 时间复杂度：O(n)。每个指针最多走完整个数组一次。
- 空间复杂度：O(1)。

## 踩坑点

- 每轮都要更新最大面积，不能只返回最后一对边界的面积。
- 先用当前的 `left`、`right` 计算面积，再移动指针，逻辑最清楚。
- 两侧高度相等时，移动任意一侧都正确。
