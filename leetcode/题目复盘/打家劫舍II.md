# 打家劫舍 II

LeetCode 213。

## 题意

沿着环形街道有一排房屋，每间房里有一定金额。相邻房屋不能同时偷，返回不触发报警时能够偷到的最大金额。

因为房屋首尾相连，所以第一间和最后一间不能同时选择。

## 我的思路

环形问题可以拆成两种互斥情况：

1. 不偷最后一间，考虑 `nums[:-1]`。
2. 不偷第一间，考虑 `nums[1:]`。

这两个子问题都变成普通的线性打家劫舍，直接复用 LeetCode 198 的状态转移，最后取两种情况的最大值。

```text
环形打家劫舍
→ 排除最后一间：nums[:-1]
→ 排除第一间：nums[1:]
→ 分别做普通打家劫舍
→ 取最大值
```

## 标准模板

```python
def rob(nums):
    n = len(nums)

    if n == 1:
        return nums[0]

    def rob_line(houses):
        n = len(houses)

        if n == 1:
            return houses[0]

        dp = [0] * (n + 1)
        dp[1] = houses[0]
        dp[2] = max(houses[0], houses[1])

        for i in range(3, n + 1):
            dp[i] = max(
                dp[i - 1],
                dp[i - 2] + houses[i - 1],
            )

        return dp[n]

    case1 = rob_line(nums[:-1])
    case2 = rob_line(nums[1:])

    return max(case1, case2)
```

## 边界判断

外层的判断：

```python
if n == 1:
    return nums[0]
```

不能删除。只有一间房时，`nums[:-1]` 和 `nums[1:]` 都会变成空数组，而第一间和最后一间实际上是同一间房。

辅助函数中的判断：

```python
if n == 1:
    return houses[0]
```

也需要保留，因为原数组长度为 `2` 时，切片后会得到长度为 `1` 的数组。

当前写法中的辅助函数不需要单独判断 `n == 0`：外层已经处理了原数组只有一间房的情况，因此后续两个切片至少都有一个元素。

## 复杂度

- 时间复杂度：O(n)，两个线性子数组各遍历一次。
- 空间复杂度：O(n)，二维情况之外还使用了切片和 DP 数组；如果不使用切片并压缩状态，可以进一步优化空间。

## 踩坑点

- 不能直接在环上套普通打家劫舍，否则可能同时选择第一间和最后一间。
- 两种情况是“不偷第一间”和“不偷最后一间”，不是分别强制偷第一间或最后一间。
- `nums[:-1]` 表示去掉最后一间，`nums[1:]` 表示去掉第一间。
- `rob_line()` 内部仍然使用普通打家劫舍的转移：`dp[i] = max(dp[i - 1], dp[i - 2] + houses[i - 1])`。
- 原数组只有一间房时必须提前返回，避免切片后出现空数组。
