# 用栈实现队列

LeetCode 232。

## 题意

只使用栈的标准操作，实现队列的 `push`、`pop`、`peek` 和 `empty`。

## 我的思路

使用两个栈。

- `in_stack` 专门接收新入队的元素。
- `out_stack` 专门提供队头元素。
- `pop` 或 `peek` 前，如果 `out_stack` 为空，则将 `in_stack` 中全部元素依次弹出、压入 `out_stack`。
- 转移后，最早进入队列的元素位于 `out_stack` 栈顶。

## 标准模板

```python
class MyQueue:

    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def _transfer(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    def pop(self):
        self._transfer()
        return self.out_stack.pop()

    def peek(self):
        self._transfer()
        return self.out_stack[-1]

    def empty(self):
        return not self.in_stack and not self.out_stack
```

## 复杂度

- `push`：O(1)。
- `pop`、`peek`：均摊 O(1)。单次转移可能是 O(n)，但每个元素最多被转移一次。
- `empty`：O(1)。
- 空间复杂度：O(n)。

## 踩坑点

- `pop(0)` 不是栈的标准操作，且时间复杂度为 O(n)，不符合题意。
- `__init__` 中的局部变量（如 `num = 0`）不能在其他方法中使用；状态应保存为 `self` 属性。
- `_transfer()` 只在 `out_stack` 为空时执行，否则会破坏先入先出的顺序。
- `pop` 取 `out_stack.pop()`，`peek` 查看 `out_stack[-1]`。
