# 平衡二叉树

LeetCode 110。

## 题意

给定二叉树，判断它是否高度平衡。高度平衡要求每个节点的左右子树高度差不超过 `1`。

## 我的思路

使用后序递归，让子树先返回结果，再判断当前节点。

- 空树高度为 `0`。
- 正常返回子树高度。
- 用 `-1` 表示子树已经不平衡，并立即向上层传递。
- 当前节点左右高度差超过 `1` 时返回 `-1`；否则返回当前树高度。

## 标准模板

```python
def check(node):
    if not node:
        return 0

    left_height = check(node.left)
    if left_height == -1:
        return -1

    right_height = check(node.right)
    if right_height == -1:
        return -1

    if abs(left_height - right_height) > 1:
        return -1

    return max(left_height, right_height) + 1

return check(root) != -1
```

## 复杂度

- 时间复杂度：O(n)，每个节点只访问一次。
- 空间复杂度：O(h)，递归栈深度为树高；最坏情况下为 O(n)。

## 踩坑点

- 不能只检查根节点的左右高度，必须检查每个节点。
- `check` 返回的是高度或 `-1`，不是直接返回布尔值。
- 发现左子树或右子树不平衡后可以立即返回 `-1`。
- 当前节点平衡时，返回 `max(left_height, right_height) + 1`。
