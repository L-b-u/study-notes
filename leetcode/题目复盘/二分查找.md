# 二分查找

LeetCode 704。

## 题意

给定一个升序排列的整数数组 `nums` 和目标值 `target`，返回 `target` 的下标；如果目标不存在，返回 `-1`。

## 我的思路

使用闭区间二分查找。

- `left` 和 `right` 表示当前仍可能包含目标的区间两端。
- 每轮取中点 `middle` 并比较 `nums[middle]` 与 `target`。
- 中点值太小就舍弃左半部分，中点值太大就舍弃右半部分。
- 找到目标立即返回下标；区间为空时返回 `-1`。

## 标准模板

```python
left = 0
right = len(nums) - 1

while left <= right:
    middle = (left + right) // 2

    if nums[middle] == target:
        return middle
    elif nums[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

return -1
```

## 复杂度

- 时间复杂度：O(log n)。
- 空间复杂度：O(1)。

## 踩坑点

- 不需要 `for i in range(len(nums))`；二分每轮搜索范围不同，使用 `while` 更清晰。
- `middle` 必须在循环内部每轮重新计算。
- 使用闭区间时，循环条件是 `left <= right`，更新时要写 `middle + 1` 和 `middle - 1`。
- 数组为空或目标不存在时，循环结束后返回 `-1`。
