# 长度最小的子数组

LeetCode 209。

## 题意

给定正整数数组 `nums` 和正整数 `target`，寻找元素和大于等于 `target` 的最短连续子数组长度；如果不存在，返回 `0`。

```text
target = 7
nums = [2, 3, 1, 2, 4, 3]

答案为 2，对应子数组 [4, 3]
```

## 我的思路

子数组要求连续，且数组元素都是正整数，可以使用滑动窗口。

- `right` 逐个加入新元素，同时用 `window_sum` 维护窗口和。
- 当 `window_sum < target` 时，继续移动 `right` 扩张窗口。
- 当 `window_sum >= target` 时，当前窗口符合条件，先记录它的长度。
- 再持续移动 `left`、减去移出的元素，尽可能缩短窗口；只要窗口仍符合条件，就继续更新最短长度。

## 标准模板

```python
left = 0
window_sum = 0
best = float("inf")

for right in range(len(nums)):
    window_sum += nums[right]

    while window_sum >= target:
        best = min(best, right - left + 1)
        window_sum -= nums[left]
        left += 1

return 0 if best == float("inf") else best
```

## 复杂度

- 时间复杂度：O(n)。`left` 和 `right` 都只会从左到右移动一次。
- 空间复杂度：O(1)。只使用了固定数量的变量。

## 踩坑点

- 先执行 `window_sum += nums[right]`，再判断是否需要收缩窗口。
- 因为目标是最短长度，窗口合法后使用 `while` 持续收缩，而不是只用 `if`。
- 每次收缩前先用 `right - left + 1` 更新 `best`，否则会漏掉当前合法窗口。
- `best` 可初始化为 `float("inf")`，最后若仍未更新则返回 `0`。
- 此做法依赖数组元素均为正整数；如果存在负数，收缩窗口后窗口和可能变大，逻辑就不再成立。
