# 在排序数组中查找元素的第一个和最后一个位置

LeetCode 34。

## 题意

给定一个升序排列的整数数组 `nums` 和目标值 `target`，找出目标值的第一个和最后一个位置。如果目标不存在，返回 `[-1, -1]`。

```text
nums = [5, 7, 7, 8, 8, 10]
target = 8

返回 [3, 4]
```

## 我的思路

使用两次二分查找。

- 第一次找左边界：命中目标后记录位置，并继续向左搜索。
- 第二次找右边界：命中目标后记录位置，并继续向右搜索。
- 如果某次二分始终没有命中，对应结果就保持 `-1`。

## 标准模板

```python
left = 0
right = len(nums) - 1
first = -1

while left <= right:
    middle = (left + right) // 2

    if nums[middle] == target:
        first = middle
        right = middle - 1
    elif nums[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

left = 0
right = len(nums) - 1
last = -1

while left <= right:
    middle = (left + right) // 2

    if nums[middle] == target:
        last = middle
        left = middle + 1
    elif nums[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

return [first, last]
```

## 复杂度

- 时间复杂度：O(log n)。执行两次二分，仍是 O(log n)。
- 空间复杂度：O(1)。

## 踩坑点

- 命中目标后不能直接返回；第一次要继续向左，第二次要继续向右。
- 命中时必须移动边界，否则会死循环。
- 目标不存在时，`first` 和 `last` 都保持 `-1`。
- 注意变量名使用 `first`，不要误写成 `frist`。
