# 不同路径

LeetCode 62。

## 题意

给定一个 `m x n` 的网格，只能向右或向下移动，返回从左上角走到右下角的不同路径数量。

## 我的思路

定义 `dp[i][j]` 表示从左上角走到坐标 `(i, j)` 的路径数量。

到达 `(i, j)` 的最后一步只有两种可能：

- 从上方 `(i - 1, j)` 向下走过来。
- 从左方 `(i, j - 1)` 向右走过来。

因此状态转移方程是：

```text
dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
```

## 标准模板

```python
def uniquePaths(m, n):
    dp = [[1] * n for _ in range(m)]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

    return dp[m - 1][n - 1]
```

## 为什么可以全部初始化为 1

第一行的所有位置只能从左边走过来，因此每个位置只有一条路径；第一列的所有位置只能从上面走过来，也只有一条路径。

所以直接使用：

```python
dp = [[1] * n for _ in range(m)]
```

就相当于同时完成了第一行和第一列的边界初始化，内部位置再使用状态转移方程计算。

例如 `3 x 4` 的网格，最终的路径数量表是：

```text
1  1  1  1
1  2  3  4
1  3  6  10
```

右下角的答案就是 `10`。

## 复杂度

- 时间复杂度：O(mn)，每个网格位置只计算一次。
- 空间复杂度：O(mn)，使用二维数组保存所有状态。

## 踩坑点

- `dp[i][j]` 表示路径数量，不是走到该位置的步数。
- 第一行和第一列不能使用普通的上下加左转移，因为它们只有一个有效方向。
- 题目坐标从 `0` 开始，所以最终答案是 `dp[m - 1][n - 1]`。
- `[[1] * n for _ in range(m)]` 会创建相互独立的行；不要写成 `[[1] * n] * m`，否则修改一行会影响其他行。
- 当前先掌握二维 DP 写法即可。虽然可以进一步压缩为一维数组，但二维状态更直观，适合先理解状态含义和转移过程。
