# 反转链表

LeetCode 206。

## 题意

给定单链表的头节点 `head`，反转链表并返回新的头节点。

```text
1 -> 2 -> 3 -> None

反转后：3 -> 2 -> 1 -> None
```

## 我的思路

使用迭代双指针：

- `prev` 表示当前节点反转后应该指向的前一个节点，初始为 `None`。
- `cur` 表示当前正在处理的节点，初始为 `head`。
- 先保存 `cur.next`，再把 `cur.next` 改为 `prev`。
- 最后同步向前移动 `prev` 和 `cur`。

## 标准模板

```python
prev = None
cur = head

while cur:
    next_node = cur.next
    cur.next = prev
    prev = cur
    cur = next_node

return prev
```

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 踩坑点

- 必须先保存 `cur.next`，再修改指针，否则会丢失后续节点。
- 循环条件使用 `while cur`，空链表时自然跳过并返回 `None`。
- 不需要虚拟头节点；`prev = None` 就表示新链表尾节点的后继为空。
- 循环结束后返回 `prev`，而不是 `cur`，因为此时 `cur` 已经是 `None`。
