# 爬楼梯

LeetCode 70。

## 题意

假设你正在爬楼梯，需要爬到楼顶。每次可以爬 1 个或 2 个台阶，返回到达楼顶的不同方法数量。

## 我的思路

定义 `dp[i]` 为到达第 `i` 阶的方法数。

- 到第 `i` 阶的最后一步可能走 1 阶，从 `i - 1` 到达。
- 也可能走 2 阶，从 `i - 2` 到达。
- 两种情况不重叠，所以 `dp[i] = dp[i - 1] + dp[i - 2]`。
- 初始值是 `dp[1] = 1`、`dp[2] = 2`。

## 标准模板

```python
def climbStairs(n):
    if n <= 2:
        return n

    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2

    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]
```

也可以只保存前两个状态：

```python
prev2, prev1 = 1, 2
for _ in range(3, n + 1):
    prev2, prev1 = prev1, prev2 + prev1
return prev1
```

## 复杂度

- 数组写法时间复杂度 O(n)，空间复杂度 O(n)。
- 变量压缩写法时间复杂度 O(n)，空间复杂度 O(1)。

## 踩坑点

- `dp[i]` 表示方法数量，不是当前走了多少步。
- `dp[1] = 1`，`dp[2] = 2`，循环从 `3` 开始。
- 题目允许的最后一步只有 1 阶或 2 阶，所以递推式只依赖前两个状态。
- `n <= 2` 可以直接返回，避免初始化数组后访问不存在的状态。
