# 单词拆分

LeetCode 139。

## 题意

给定字符串 `s` 和字典 `wordDict`，判断是否可以使用字典中的一个或多个单词拼接出 `s`。

字典中的单词可以重复使用，不要求字典中的所有单词都使用。

## 我的思路

这道题需要判断字符串能不能被切分成多个字典单词，可以使用一维动态规划。

定义：

```text
dp[i]：s 的前 i 个字符能否由字典中的单词拼出来
```

判断 `dp[i]` 时，枚举一个切分位置 `j`，把前 `i` 个字符分成两部分：

```text
s[0:j] + s[j:i]
```

如果：

1. 前半部分可以拼出，即 `dp[j] == True`。
2. 后半部分 `s[j:i]` 在字典中。

那么前 `i` 个字符也可以拼出：

```python
dp[i] = True
```

## 标准模板

```python
def wordBreak(s, wordDict):
    word_set = set(wordDict)
    n = len(s)

    # dp[i]：s 的前 i 个字符能否被拼出
    dp = [False] * (n + 1)
    dp[0] = True

    for i in range(1, n + 1):
        for j in range(i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break

    return dp[n]
```

## 为什么 `dp[0] = True`

`dp[0]` 表示空字符串是否可以被拼出。将它设为 `True`，是为了支持单词从字符串开头开始匹配。

例如：

```python
s = "leet"
wordDict = ["leet"]
```

判断 `s[0:4]` 时：

```python
dp[0] == True
s[0:4] == "leet"
```

因此可以推出 `dp[4] = True`。

## 示例

```python
s = "leetcode"
wordDict = ["leet", "code"]
```

拆分过程：

```text
leet + code
```

先得到：

```text
dp[4] = True
```

再利用 `s[4:8] = "code"` 在字典中，得到：

```text
dp[8] = True
```

最终返回 `dp[len(s)]`，结果为 `True`。

另一个例子：

```python
s = "applepenapple"
wordDict = ["apple", "pen"]
```

可以拆分为：

```text
apple + pen + apple
```

字典中的单词允许重复使用，因此结果也是 `True`。

## 为什么使用集合

```python
word_set = set(wordDict)
```

代码需要频繁判断子串是否在字典中。集合的平均查找复杂度为 O(1)，比直接在列表中查找更适合。

## 复杂度

- 时间复杂度：通常记为 O(n^2)，需要枚举字符串中的切分位置；子串切片和哈希处理的具体成本与语言实现有关。
- 空间复杂度：O(n)，主要使用 `dp` 数组和字典集合。

## 踩坑点

- `dp[i]` 表示前 `i` 个字符，不是下标为 `i` 的字符。
- Python 切片 `s[j:i]` 是左闭右开区间，包含 `j`，不包含 `i`。
- `dp[0]` 必须初始化为 `True`，否则无法匹配从字符串开头开始的单词。
- 返回的是 `dp[n]`，表示整个字符串能否被拼出。
- 字典中的单词可以重复使用，所以不需要删除已经使用过的单词。
- 只要找到一种可行切分，就可以将 `dp[i]` 设为 `True` 并 `break`。
