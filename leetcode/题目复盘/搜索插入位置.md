# 搜索插入位置

LeetCode 35。

## 题意

给定一个无重复元素的升序数组 `nums` 和目标值 `target`。如果目标存在，返回它的下标；如果不存在，返回它按顺序插入后的位置。

```text
nums = [1, 3, 5, 6]
target = 2

返回 1。
```

## 我的思路

复用第 704 题的闭区间二分查找。

- 找到目标时直接返回 `middle`。
- 中间值小于目标时，目标只能在右侧，移动 `left`。
- 中间值大于目标时，目标只能在左侧，移动 `right`。
- 如果目标不存在，循环结束时 `left` 指向第一个大于等于目标的位置，因此返回 `left`。

## 标准模板

```python
left = 0
right = len(nums) - 1

while left <= right:
    middle = (left + right) // 2

    if nums[middle] == target:
        return middle
    elif nums[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

return left
```

## 复杂度

- 时间复杂度：O(log n)。
- 空间复杂度：O(1)。

## 踩坑点

- 目标不存在时不是返回 `-1`，而是返回最终的 `left`。
- `left` 的含义是当前候选区间的左边界；循环结束时，它越过了所有小于 `target` 的元素。
- 目标小于所有元素返回 `0`，大于所有元素返回 `len(nums)`，空数组返回 `0`。
