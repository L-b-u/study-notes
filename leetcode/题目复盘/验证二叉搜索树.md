# 验证二叉搜索树

LeetCode 98。

## 题意

给定二叉树根节点 `root`，判断它是否为有效的二叉搜索树（BST）：每个节点的左子树所有节点值都小于该节点，右子树所有节点值都大于该节点，并且左右子树自身也都必须是 BST。

## 我的思路

使用递归为每个节点传递允许的取值范围 `(lower, upper)`。

- 根节点初始范围是负无穷到正无穷。
- 当前节点必须严格满足 `lower < node.val < upper`。
- 进入左子树时，当前节点值成为上界。
- 进入右子树时，当前节点值成为下界。
- 空节点满足条件。

## 标准模板

```python
def isValidBST(root):
    def check(node, lower, upper):
        if not node:
            return True

        if not lower < node.val < upper:
            return False

        return (
            check(node.left, lower, node.val)
            and check(node.right, node.val, upper)
        )

    return check(root, float("-inf"), float("inf"))
```

## 复杂度

- 时间复杂度：O(n)，每个节点最多检查一次。
- 空间复杂度：O(h)，递归调用栈深度为树高；最坏情况下为 O(n)。

## 踩坑点

- 只比较节点与左右孩子不够；祖先施加的范围必须传递到整个子树。
- 左子树的上界是当前节点值；右子树的下界是当前节点值。
- BST 采用严格大小关系，重复值不合法。
- 空树是有效 BST，递归遇到空节点返回 `True`。
