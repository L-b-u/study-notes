# 每日温度

LeetCode 739。

## 题意

给定每天的温度，返回每一天需要等待多少天才能遇到更高的温度；如果之后没有更高温度，返回 `0`。

```text
temperatures = [73, 74, 75, 71, 69, 72, 76, 73]

答案为 [1, 1, 4, 2, 1, 1, 0, 0]
```

## 我的思路

使用单调递减栈，栈中保存还没有找到更高温度的下标。

- 从左到右扫描，当前下标为 `right`。
- 只要当前温度高于栈顶下标对应的温度，当前温度就是那一天遇到的下一个更高温度；弹出下标并记录距离 `right - previous`。
- 当前温度不高于栈顶时，直接入栈等待。
- 扫描结束后，栈中剩余下标没有更高温度，结果保持 `0`。

## 标准模板

```python
result = [0] * len(temperatures)
stack = []

for right in range(len(temperatures)):
    while stack and temperatures[right] > temperatures[stack[-1]]:
        previous = stack.pop()
        result[previous] = right - previous

    stack.append(right)

return result
```

## 复杂度

- 时间复杂度：O(n)。每个下标最多入栈和出栈一次。
- 空间复杂度：O(n)。最坏情况下温度单调递减，所有下标都留在栈中。

## 踩坑点

- 栈中保存下标而不是温度值，因为需要计算等待天数。
- 使用 `while`，当前温度可能一次解决栈顶多个更低温度。
- 只有当前温度严格更高时才弹出；相等温度不能算“更高”。
- 遍历结束后没有更高温度的下标不需要额外处理，结果初始为 `0`。
