# 水果成篮

LeetCode 904。

## 题意

给定数组 `fruits`，每个数字代表一种水果。只能选择连续的一段树，并且篮子中最多容纳两种水果；返回最多能采摘的水果数量。

等价于：寻找最多包含两种不同元素的最长连续子数组长度。

```text
fruits = [1, 2, 1]

答案为 3，对应整个数组。
```

## 我的思路

使用可变长度滑动窗口。

- `window` 记录当前窗口内每种水果的数量。
- `right` 向右扩张窗口，纳入新水果。
- 若水果种类数超过 2，持续移动 `left`，并减少移出水果的计数；计数变为 `0` 时删除该水果。
- 窗口重新合法后，用窗口长度更新历史最大值。

## 标准模板

```python
left = 0
window = {}
best = 0

for right in range(len(fruits)):
    fruit = fruits[right]
    window[fruit] = window.get(fruit, 0) + 1

    while len(window) > 2:
        left_fruit = fruits[left]
        window[left_fruit] -= 1
        if window[left_fruit] == 0:
            del window[left_fruit]
        left += 1

    best = max(best, right - left + 1)

return best
```

## 复杂度

- 时间复杂度：O(n)。左右指针都只向右移动，每个水果最多进入和离开窗口一次。
- 空间复杂度：O(1)。窗口中最多只保存两种水果。

## 踩坑点

- `len(window)` 表示水果种类数，而不是窗口长度。
- 种类数超过 2 时用 `while` 收缩，因为一次移出一种水果后，可能仍有三种水果。
- 移出水果计数为 `0` 时必须删除键，否则种类数不会减少。
- 窗口只有一种水果时也合法，因此每次窗口合法后都更新 `best`。
- 题目求全局最长长度，不能在窗口中恰好有两种水果时提前返回。
