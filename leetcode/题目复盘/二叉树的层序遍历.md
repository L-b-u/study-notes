# 二叉树的层序遍历

LeetCode 102。

## 题意

给定二叉树根节点 `root`，返回按层序从上到下、每层从左到右排列的节点值列表。

```text
    3
   / \
  9  20
     / \
    15  7

返回 [[3], [9, 20], [15, 7]]
```

## 我的思路

使用队列进行广度优先遍历。

- 根节点先入队。
- 每轮开始时取当前队列长度，作为这一层的节点数量。
- 恰好处理这些节点，并将它们的左右孩子加入队列。
- 当前层处理完后，把该层的值列表加入结果。

## 标准模板

```python
from collections import deque

result = []
if not root:
    return result

queue = deque([root])
while queue:
    level = []

    for _ in range(len(queue)):
        node = queue.popleft()
        level.append(node.val)

        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)

    result.append(level)

return result
```

## 复杂度

- 时间复杂度：O(n)，每个节点入队、出队一次。
- 空间复杂度：O(n)，队列最宽时可能保存一层的所有节点。

## 踩坑点

- 每层开始时固定 `len(queue)`；不要让本层新加入的孩子也在同一轮被处理。
- 需要使用队列先进先出的顺序；`deque.popleft()` 是高效的队头操作。
- 空树直接返回空列表。
- 每层单独建立 `level`，处理完一整层后再加入结果。
