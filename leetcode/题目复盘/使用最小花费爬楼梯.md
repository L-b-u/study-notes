# 使用最小花费爬楼梯

LeetCode 746。

## 题意

给定数组 `cost`，其中 `cost[i]` 是从第 `i` 阶向上走一步或两步时需要支付的费用。可以从第 `0` 阶或第 `1` 阶开始，返回到达楼顶的最低花费。

## 我的思路

定义 `dp[i]` 为到达第 `i` 阶位置的最小花费，其中 `i = len(cost)` 表示楼顶。

- 可以从第 `i - 1` 阶走一步到达 `i`，支付 `cost[i - 1]`。
- 也可以从第 `i - 2` 阶走两步到达 `i`，支付 `cost[i - 2]`。
- 因此取两种方案的较小值。
- 因为可以从第 0 阶或第 1 阶开始，`dp[0] = dp[1] = 0`。

## 标准模板

```python
def minCostClimbingStairs(cost):
    n = len(cost)
    dp = [0] * (n + 1)

    dp[0] = 0
    dp[1] = 0

    for i in range(2, n + 1):
        dp[i] = min(
            dp[i - 1] + cost[i - 1],
            dp[i - 2] + cost[i - 2],
        )

    return dp[n]
```

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(n)；由于只依赖前两个状态，也可以压缩到 O(1)。

## 踩坑点

- `dp[1]` 应为 `0`，因为题目允许直接从第 1 阶开始；不能默认必须支付 `cost[0]`。
- `dp[n]` 表示楼顶，不是最后一个数组下标。
- 从 `i - 1` 到达楼顶时支付 `cost[i - 1]`，从 `i - 2` 到达时支付 `cost[i - 2]`。
- 循环从 `2` 开始，因为 `dp[0]` 和 `dp[1]` 是初始状态。
