# 最长公共子序列

LeetCode 1143。

## 题意

给定两个字符串 `text1` 和 `text2`，返回它们最长公共子序列的长度。

子序列不要求连续，但必须保持字符在原字符串中的相对顺序。

## 我的思路

这是两个字符串之间的二维动态规划问题。

定义：

```text
dp[i][j]：text1 的前 i 个字符和 text2 的前 j 个字符的最长公共子序列长度
```

这里的 `i`、`j` 表示字符数量，不是数组下标，因此 `dp` 需要开成 `(m + 1) x (n + 1)`。

空字符串和任何字符串都没有公共子序列，所以第一行和第一列都是 `0`。

## 状态转移

实际比较的字符是：

```python
text1[i - 1]
text2[j - 1]
```

因为 `i` 表示前 `i` 个字符，而 Python 下标从 `0` 开始。

### 当前字符相等

如果：

```python
text1[i - 1] == text2[j - 1]
```

说明这两个字符可以作为公共子序列的最后一个字符。因此：

```python
dp[i][j] = dp[i - 1][j - 1] + 1
```

也就是：去掉两个当前字符，先求前面部分的答案，再加上当前匹配的字符。

### 当前字符不相等

如果两个当前字符不相等，它们不能同时作为公共子序列的一部分，只能舍弃其中一个：

```python
dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
```

- `dp[i - 1][j]`：舍弃 `text1` 的当前字符。
- `dp[i][j - 1]`：舍弃 `text2` 的当前字符。

## 标准模板

```python
def longestCommonSubsequence(text1, text2):
    m = len(text1)
    n = len(text2)

    # dp[i][j]：两个前缀的最长公共子序列长度
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(
                    dp[i - 1][j],
                    dp[i][j - 1],
                )

    return dp[m][n]
```

## 示例

```python
text1 = "abcde"
text2 = "ace"
```

最长公共子序列是：

```text
"ace"
```

长度为 `3`。

注意：`ace` 不是连续子串，但字符顺序和原字符串一致，所以它是子序列。

## 转移过程示例

```python
text1 = "ab"
text2 = "ac"
```

比较最后两个字符时：

```text
text1[1] = "b"
text2[1] = "c"
```

两个字符不相等，因此：

```python
dp[2][2] = max(dp[1][2], dp[2][1])
```

含义是：

```text
舍弃 text1 的 b，或者舍弃 text2 的 c
```

两种情况下都可以保留公共字符 `a`，所以答案是 `1`。

## 复杂度

- 时间复杂度：O(mn)，需要计算每个二维状态。
- 空间复杂度：O(mn)，使用二维数组保存状态。

## 和最长公共子串的区别

| 问题 | 是否要求连续 | 不相等时的处理 |
| --- | --- | --- |
| 最长公共子序列 | 不要求连续 | 取上方和左方最大值 |
| 最长公共子串 | 必须连续 | 通常将当前状态置为 `0` |

## 踩坑点

- `dp[i][j]` 表示前 `i` 个和前 `j` 个字符，不是下标为 `i`、`j` 的字符。
- 比较字符时要使用 `text1[i - 1]` 和 `text2[j - 1]`。
- 字符相等时看左上角：`dp[i - 1][j - 1] + 1`。
- 字符不等时取上方和左方最大值。
- 最终返回 `dp[m][n]`，表示两个完整字符串的答案。
- 子序列可以不连续，但不能改变字符的相对顺序。
