# 二叉树的前序遍历

LeetCode 144。

## 题意

给定二叉树的根节点 `root`，返回它的前序遍历结果。前序顺序为：根节点、左子树、右子树。

## 我的思路

先写递归版本理解遍历顺序，再使用显式栈实现迭代版本。

- 空节点不处理。
- 访问当前节点并记录值。
- 右节点先入栈，左节点后入栈，利用栈的后进先出保证左节点先访问。

## 标准模板

```python
result = []
if not root:
    return result

stack = [root]
while stack:
    node = stack.pop()
    result.append(node.val)

    if node.right:
        stack.append(node.right)
    if node.left:
        stack.append(node.left)

return result
```

递归版本也可以写成：

```python
result = []

def dfs(node):
    if not node:
        return
    result.append(node.val)
    dfs(node.left)
    dfs(node.right)

dfs(root)
return result
```

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(h)，递归调用栈或显式栈最多保存树高数量级的节点。

## 踩坑点

- 栈中右节点必须先入、左节点后入，否则遍历会变成“根、右、左”。
- 空树要直接返回空列表。
- 递归的空节点分支只需 `return`，返回值由外层 `result` 统一维护。
- 迭代写法能避免极深二叉树触发 Python 递归深度限制。
