# 删除有序数组中的重复项

LeetCode 26。

## 题意

给定升序数组，原地删除重复元素，返回不重复元素的数量 `k`。前 `k` 个位置应保存不重复元素，后面的内容不重要。

## 我的思路

使用同向快慢指针。

- `slow` 指向当前已保留的最后一个不重复元素。
- `fast` 从第二个元素起扫描后续元素。
- 当 `nums[fast]` 与 `nums[slow]` 不同，说明发现新元素：先 `slow += 1`，再将新元素复制到 `nums[slow]`。
- 最终不重复元素个数为 `slow + 1`。

## 标准模板

```python
slow = 0

for fast in range(1, len(nums)):
    if nums[slow] != nums[fast]:
        slow += 1
        nums[slow] = nums[fast]

return slow + 1
```

## 过程示例

```text
nums = [1, 1, 2, 2, 3]

fast = 1：与 nums[slow] 相同，跳过。
fast = 2：发现 2，slow 移到 1，复制 nums[1] = 2。
fast = 3：与 nums[slow] 相同，跳过。
fast = 4：发现 3，slow 移到 2，复制 nums[2] = 3。

返回 3，nums[:3] 为 [1, 2, 3]。
```

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(1)。

## 踩坑点

- 这里是复制，不是交换。
- 返回的是 `slow + 1`，因为下标从 0 开始。
- LeetCode 26 保证数组至少有一个元素；若题目允许空数组，需要先处理 `if not nums: return 0`。
