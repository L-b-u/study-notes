# 对称二叉树

LeetCode 101。

## 题意

给定二叉树根节点 `root`，判断它是否关于中心轴对称。

## 我的思路

将根节点左右子树看作两个需要比较的节点，递归判断它们是否互为镜像。

- 两个节点都为空，镜像成立。
- 只有一个为空，镜像不成立。
- 两个节点值不同，镜像不成立。
- 节点值相同时，比较外侧 `a.left` 与 `b.right`，以及内侧 `a.right` 与 `b.left`。

## 标准模板

```python
def isSymmetric(root):
    if not root:
        return True

    def mirror(a, b):
        if not a and not b:
            return True
        if not a or not b:
            return False
        if a.val != b.val:
            return False

        return mirror(a.left, b.right) and mirror(a.right, b.left)

    return mirror(root.left, root.right)
```

## 复杂度

- 时间复杂度：O(n)，每个节点最多比较一次。
- 空间复杂度：O(h)，递归调用栈深度为树高；最坏情况下为 O(n)。

## 踩坑点

- 空树视为对称，先返回 `True`，避免访问 `root.left` 报错。
- 最后必须写 `return mirror(root.left, root.right)`；只调用不返回会得到 `None`。
- 镜像比较是交叉方向：`a.left` 对 `b.right`，`a.right` 对 `b.left`。
- 迭代法也是成对比较节点，队列中保存的是节点对而不是单个节点。
