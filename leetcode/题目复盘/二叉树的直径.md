# 二叉树的直径

LeetCode 543。

## 题意

给定二叉树根节点 `root`，返回树中任意两个节点之间最长路径的边数。这条路径不一定经过根节点。

## 我的思路

使用后序递归，在计算子树深度的同时更新最大直径。

- 递归函数返回当前子树的最大深度。
- 对每个节点，经过它的最长路径边数为 `left_depth + right_depth`。
- 使用 `self.max_result` 记录所有节点对应路径中的最大值。
- 当前节点向父节点返回 `max(left_depth, right_depth) + 1`。

## 标准模板

```python
self.max_result = 0

def tree_depth(node):
    if not node:
        return 0

    left_depth = tree_depth(node.left)
    right_depth = tree_depth(node.right)

    self.max_result = max(
        self.max_result,
        left_depth + right_depth,
    )

    return max(left_depth, right_depth) + 1

tree_depth(root)
return self.max_result
```

## 复杂度

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归调用栈深度为树高；最坏情况下为 O(n)。

## 踩坑点

- 最长路径不一定经过根节点，因此必须在每个节点更新全局答案。
- `tree_depth` 返回的是子树深度，不是直径。
- 直径按边数计算，所以经过当前节点的直径是 `left_depth + right_depth`，不需要再加 `1`。
- 若使用外层局部变量，需要声明 `nonlocal`；在 LeetCode 的 `Solution` 类中也可以使用实例属性。
- 实例属性必须在每次调用方法时重新初始化，避免残留上一次调用的答案。
