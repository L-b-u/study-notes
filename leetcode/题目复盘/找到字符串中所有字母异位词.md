# 找到字符串中所有字母异位词

LeetCode 438。

## 题意

给定字符串 `s` 和 `p`，找出 `s` 中所有 `p` 的字母异位词子串，并按起始下标返回结果。

字母异位词的字符种类和每种字符的出现次数均相同，因此长度一定相同。

```text
s = "cbaebabacd"
p = "abc"

答案为 [0, 6]，对应 "cba" 和 "bac"
```

## 我的思路

使用固定长度的滑动窗口。

- `need` 统计 `p` 中每个字符出现的次数。
- `window` 统计当前窗口内每个字符出现的次数。
- `right` 每次加入一个字符；当窗口长度超过 `len(p)` 时，移动 `left` 并移出最左字符。
- 窗口长度等于 `len(p)` 时，若 `window == need`，当前 `left` 就是一个答案下标。

## 标准模板

```python
left = 0
res = []
need = {}
window = {}

for char in p:
    need[char] = need.get(char, 0) + 1

for right in range(len(s)):
    right_char = s[right]
    window[right_char] = window.get(right_char, 0) + 1

    while right - left + 1 > len(p):
        left_char = s[left]
        window[left_char] -= 1
        if window[left_char] == 0:
            del window[left_char]
        left += 1

    if window == need:
        res.append(left)

return res
```

## 复杂度

- 时间复杂度：O(n)，其中 n 是 `s` 的长度。每个字符最多加入和移出窗口一次。
- 空间复杂度：O(k)，其中 k 是 `p` 中不同字符的数量。

## 踩坑点

- `need[char] += 1` 会在首次出现字符时因键不存在而报错，应使用 `need.get(char, 0) + 1`。
- `for right in s` 得到的是字符而不是下标；要计算窗口长度和访问 `s[left]`，使用 `for right in range(len(s))`。
- `len(window)` 是不同字符的种类数，不是窗口长度；窗口长度是 `right - left + 1`。
- 左侧字符计数减到 `0` 后要删除该键，否则与 `need` 比较时会不相等。
- 这题只在窗口长度恰好等于 `len(p)` 时比较，不需要像第 209 题那样按条件持续缩短合法窗口。
