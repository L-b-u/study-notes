# 二叉树的最大深度

LeetCode 104。

## 题意

给定二叉树根节点 `root`，返回从根节点到最远叶子节点的最长路径上的节点数。空树深度为 `0`。

## 我的思路

使用递归计算左右子树的深度：当前树的深度等于左右子树较大深度加上根节点这一层。

```text
depth(node) = max(depth(node.left), depth(node.right)) + 1
```

当节点为空时返回 `0`，这是递归的基本情况。

## 标准模板

```python
def maxDepth(root):
    if not root:
        return 0

    left_depth = maxDepth(root.left)
    right_depth = maxDepth(root.right)
    return max(left_depth, right_depth) + 1
```

## 复杂度

- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(h)，递归调用栈的最大深度是树高；最坏情况下为 O(n)。

## 踩坑点

- 空节点返回 `0`，叶节点因此返回 `1`。
- 需要取左右子树深度的较大值，再加当前节点这一层。
- 递归简洁直观；若树可能极深，可考虑用层序遍历迭代统计层数。
