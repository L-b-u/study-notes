# 定长子串中元音的最大数目

LeetCode 1456。

## 题意

给定字符串 `s` 和整数 `k`，返回 `s` 中长度为 `k` 的子串所包含的最大元音字母数量。

```text
s = "abciiidef"
k = 3

答案为 3，对应子串 "iii"。
```

## 我的思路

使用固定长度滑动窗口。

- 右指针每读入一个字符，如果它是元音，`vowel_count` 加一。
- 窗口长度超过 `k` 时，左指针移出一个字符；若移出的是元音，`vowel_count` 减一。
- 窗口长度恰好为 `k` 时，用当前元音数量更新最大值。

## 标准模板

```python
left = 0
vowels = {"a", "e", "i", "o", "u"}
vowel_count = 0
best = 0

for right in range(len(s)):
    if s[right] in vowels:
        vowel_count += 1

    while right - left + 1 > k:
        if s[left] in vowels:
            vowel_count -= 1
        left += 1

    if right - left + 1 == k:
        best = max(best, vowel_count)

return best
```

## 复杂度

- 时间复杂度：O(n)。每个字符最多进入和移出窗口一次。
- 空间复杂度：O(1)。元音集合大小固定，只维护固定数量变量。

## 踩坑点

- `k` 是窗口固定长度，不是可使用次数；窗口过长的判断是 `right - left + 1 > k`。
- 只有窗口长度等于 `k` 时才更新 `best`。
- 本题只关心元音数量，使用 `vowel_count` 即可，不需要为每个字符建立字典。
- 指针变量拼写为 `right`，字典的默认取值调用是 `dict.get(key, 0)`；但本题可直接省去字典。
