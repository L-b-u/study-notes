# 有效的括号

LeetCode 20。

## 题意

给定只包含括号字符的字符串 `s`，判断括号是否有效。要求括号按正确顺序闭合，且每个右括号都匹配最近的同类型左括号。

```text
s = "()[]{}"  -> True
s = "(]"      -> False
```

## 我的思路

使用栈维护尚未匹配的左括号。

- 遇到左括号，入栈。
- 遇到右括号，先检查栈不为空，再检查栈顶是否是对应的左括号。
- 匹配成功后弹出栈顶。
- 遍历结束时，只有栈为空才说明所有括号都已匹配。

## 标准模板

```python
pairs = {
    ")": "(",
    "]": "[",
    "}": "{",
}
stack = []

for char in s:
    if char in "([{":
        stack.append(char)
    else:
        if not stack or stack[-1] != pairs[char]:
            return False
        stack.pop()

return len(stack) == 0
```

## 复杂度

- 时间复杂度：O(n)。
- 空间复杂度：O(n)。

## 踩坑点

- 右括号不能无条件出栈，必须先检查栈非空和栈顶匹配。
- `s = "]"` 时栈为空，访问 `stack[-1]` 前必须先判断。
- 只要发现不匹配就可以立即返回 `False`。
- 遍历结束后仍要检查栈是否为空，例如 `"(("` 不合法。
