# 翻转二叉树

LeetCode 226。

## 题意

给定二叉树根节点 `root`，翻转整棵二叉树，并返回翻转后的根节点。翻转意味着每个节点的左右子树互换。

## 我的思路

使用递归：

- 空节点直接返回。
- 交换当前节点的左右子树。
- 递归翻转交换后的左右子树。
- 返回当前根节点。

## 标准模板

```python
def invertTree(root):
    if not root:
        return None

    root.left, root.right = root.right, root.left
    invertTree(root.left)
    invertTree(root.right)
    return root
```

## 复杂度

- 时间复杂度：O(n)，每个节点访问并交换一次。
- 空间复杂度：O(h)，递归调用栈的深度等于树高；最坏情况下为 O(n)。

## 踩坑点

- 空节点必须直接返回，否则访问 `root.left` 会报错。
- 交换后递归的是新的 `root.left` 和 `root.right`，当前写法顺序正确。
- 必须返回 `root`，否则调用方拿不到翻转后的树。
- 单节点和空树翻转后结构不变。
