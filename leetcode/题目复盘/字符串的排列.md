# 字符串的排列

LeetCode 567。

## 题意

给定两个字符串 `s1` 和 `s2`，判断 `s2` 是否包含 `s1` 的任意排列。

```text
s1 = "ab"
s2 = "eidbaooo"

返回 True，因为 "ba" 是 "ab" 的排列。
```

## 我的思路

这是固定长度滑动窗口，与 LeetCode 438「找到字符串中所有字母异位词」使用同一套逻辑。

- `need` 记录 `s1` 的字符次数。
- 在 `s2` 上滑动长度为 `len(s1)` 的窗口，`window` 记录窗口内的字符次数。
- 窗口长度超过 `len(s1)` 时，从左侧移出字符，并在计数为 `0` 时删除该键。
- 当 `window == need` 时，说明当前窗口是 `s1` 的一个排列，直接返回 `True`。

## 标准模板

```python
left = 0
need = {}
window = {}

for char in s1:
    need[char] = need.get(char, 0) + 1

for right in range(len(s2)):
    right_char = s2[right]
    window[right_char] = window.get(right_char, 0) + 1

    while right - left + 1 > len(s1):
        left_char = s2[left]
        window[left_char] -= 1
        if window[left_char] == 0:
            del window[left_char]
        left += 1

    if window == need:
        return True

return False
```

## 复杂度

- 时间复杂度：O(n)，其中 n 是 `s2` 的长度。左右指针都只向右移动。
- 空间复杂度：O(k)，其中 k 是窗口中不同字符的数量。

## 踩坑点

- `need` 由较短的目标字符串 `s1` 构建，窗口在 `s2` 上移动。
- 窗口的目标长度是 `len(s1)`，不是不同字符的种类数。
- 移出字符后，如果计数为 `0`，必须从 `window` 中删除，才能直接用 `window == need` 判断。
- 和 LeetCode 438 的区别只在结果：本题找到一个匹配窗口即可提前返回 `True`，不需要收集所有下标。
