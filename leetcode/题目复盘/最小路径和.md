# 最小路径和

LeetCode 64。

## 题意

给定一个 `m x n` 的网格，每个格子有一个非负整数。只能向右或向下移动，返回从左上角走到右下角的最小路径和。

路径和包含经过的起点和终点格子的值。

## 我的思路

定义 `dp[i][j]` 表示从左上角走到坐标 `(i, j)` 的最小路径和。

到达当前格子的最后一步只有两种可能：

- 从上方 `(i - 1, j)` 走下来。
- 从左方 `(i, j - 1)` 走过来。

因此选择上方和左方路径和较小的一条，再加上当前格子的值：

```text
dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
```

其中 `grid[i][j]` 表示当前格子的代价。

## 标准模板

```python
def minPathSum(grid):
    m = len(grid)
    n = len(grid[0])

    # dp[i][j]：从左上角走到 (i, j) 的最小路径和
    dp = [[0] * n for _ in range(m)]

    # 起点
    dp[0][0] = grid[0][0]

    # 第一行只能从左边走过来
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]

    # 第一列只能从上边走过来
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]

    # 其余位置从上方和左方选择较小值
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(
                dp[i - 1][j],
                dp[i][j - 1],
            ) + grid[i][j]

    return dp[m - 1][n - 1]
```

## 示例

```python
grid = [
    [1, 3, 1],
    [1, 5, 1],
    [4, 2, 1],
]
```

计算得到的 `dp` 表是：

```text
1  4  5
2  7  6
6  8  7
```

最小路径为：

```text
1 → 3 → 1 → 1 → 1
```

答案是 `7`。

## 边界初始化

- 起点：`dp[0][0] = grid[0][0]`。
- 第一行：只能从左边走过来，所以累加左侧结果。
- 第一列：只能从上边走过来，所以累加上方结果。
- 其他位置：同时考虑上方和左方。

第一行和第一列不能直接套用普通转移，因为它们分别只有一个有效方向。

## 复杂度

- 时间复杂度：O(mn)，每个格子只计算一次。
- 空间复杂度：O(mn)，使用二维数组保存状态。

## 和不同路径的区别

两道题的网格 DP 框架相同，区别在于状态含义和转移方式：

```text
不同路径：dp[i][j] = 上方路径数 + 左方路径数
最小路径和：dp[i][j] = min(上方路径和, 左方路径和) + 当前格子值
```

## 踩坑点

- `grid[i][j]` 是当前格子的代价，不是坐标或路径数量。
- 路径和包含起点 `grid[0][0]` 和终点 `grid[m - 1][n - 1]`。
- 最后一格返回 `dp[m - 1][n - 1]`，不是 `grid[m - 1][n - 1]`。
- 第一行和第一列需要单独初始化，不能访问不存在的 `dp[-1][j]` 或 `dp[i][-1]`。
- 当前先掌握二维 DP 写法即可，重点是理解状态定义、边界和转移方程。
