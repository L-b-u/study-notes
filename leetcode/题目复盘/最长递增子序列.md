# 最长递增子序列

LeetCode 300。

## 题意

给定一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

子序列不要求连续，但必须保持原数组中的相对顺序。

## 我的思路

使用动态规划。遍历每个数字，判断它能否接在前面某个更小的数字后面。

## 状态定义

```text
dp[i]：以 nums[i] 结尾的最长递增子序列长度
```

每个数字本身都可以单独组成长度为 `1` 的递增子序列，因此：

```python
dp = [1] * n
```

## 状态转移

对于当前下标 `i`，枚举前面的下标 `j`：

```python
if nums[j] < nums[i]:
    dp[i] = max(dp[i], dp[j] + 1)
```

含义是：如果 `nums[j]` 小于 `nums[i]`，那么 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面。

## 标准模板

```python
def lengthOfLIS(nums):
    n = len(nums)

    # dp[i]：以 nums[i] 结尾的最长递增子序列长度
    dp = [1] * n

    for i in range(1, n):
        for j in range(0, i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)
```

## 示例

```python
nums = [10, 9, 2, 5, 3, 7, 101, 18]
```

其中一条最长递增子序列是：

```text
2, 5, 7, 101
```

长度为 `4`。

对应的 `dp` 结果可以理解为：

```text
下标：  0  1  2  3  4  5  6  7
数字： 10  9  2  5  3  7 101 18
dp：    1  1  1  2  2  3  4  4
```

## 为什么返回 `max(dp)`

`dp[i]` 表示的是“以 `nums[i]` 结尾”的答案，而最长递增子序列不一定以数组最后一个元素结尾。

例如：

```python
nums = [1, 2, 3, 0]
```

最长递增子序列是 `1, 2, 3`，长度为 `3`，但最后一个元素 `0` 不能接在前面递增序列后面。

因此不能返回 `dp[n - 1]`，而要返回所有状态中的最大值：

```python
return max(dp)
```

## 复杂度

- 时间复杂度：O(n²)，每个 `i` 都要枚举前面的 `j`。
- 空间复杂度：O(n)，使用 `dp` 数组保存每个位置的状态。

## 踩坑点

- `dp[i]` 是以 `nums[i]` 结尾的长度，不是前 `i` 个元素的全局最优值。
- 每个位置初始值应为 `1`，因为单个元素本身就是长度为 `1` 的子序列。
- 严格递增要求使用 `nums[j] < nums[i]`，不能写成 `<=`。
- 内层循环只能遍历当前元素之前的位置：`range(0, i)`。
- 最终返回 `max(dp)`，不能直接返回最后一个状态。
- 子序列不要求连续，只要求元素顺序不变。

## 代码问题复盘

开始写代码时容易出现以下问题：

```python
dp = [0] * (n + 1)
```

这里的状态和下标不匹配。当前定义是 `dp[i]` 对应 `nums[i]`，因此应使用长度为 `n` 的数组，并初始化为 `1`。

```python
range1(2, n + 1)
```

Python 的正确写法是：

```python
range(1, n)
```

内层循环应写成：

```python
for j in range(0, i):
```

因为 `j` 要从数组开头遍历到当前下标 `i` 之前。
