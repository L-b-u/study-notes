# 合并两个有序链表

LeetCode 21。

## 题意

将两个升序链表合并为一个新的升序链表，并返回合并后的头节点。

## 我的思路

使用虚拟头节点和尾指针。

- `dummy` 是独立的占位节点，不指向某一个输入链表。
- `tail` 指向结果链表当前尾部。
- 比较 `list1` 和 `list2` 当前节点，把较小节点接到 `tail.next`，并移动对应链表指针。
- 两个链表中有一个为空后，把另一个剩余部分直接接到尾部。
- 返回 `dummy.next`，跳过占位节点。

## 标准模板

```python
dummy = ListNode(0)
tail = dummy

while list1 and list2:
    if list1.val <= list2.val:
        tail.next = list1
        list1 = list1.next
    else:
        tail.next = list2
        list2 = list2.next
    tail = tail.next

tail.next = list1 if list1 else list2
return dummy.next
```

## 复杂度

- 时间复杂度：O(m + n)，其中 `m`、`n` 是两个链表的长度。
- 空间复杂度：O(1)，只复用原有节点，不额外创建结果节点。

## 踩坑点

- `dummy` 是独立的结果占位节点，不需要指向 `list1` 或 `list2`。
- 每次连接节点后要移动 `tail`，否则会重复覆盖同一个位置。
- 循环结束后要接上未处理的剩余链表。
- 返回 `dummy.next`，不能返回 `dummy`。
