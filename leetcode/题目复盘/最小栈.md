# 最小栈

LeetCode 155。

## 题意

设计一个栈，支持 `push`、`pop`、`top` 和 `getMin` 操作，并且 `getMin` 能在常数时间内返回栈中的最小元素。

## 我的思路

使用两个同步栈：

- `stack` 保存实际入栈的元素。
- `min_stack` 在每一层保存当前栈的最小值。

入栈时，将新值与 `min_stack` 栈顶比较，记录较小者；出栈时两个栈同时弹出。这样 `getMin` 只需读取 `min_stack[-1]`。

## 标准模板

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, value):
        self.stack.append(value)
        if self.min_stack:
            current_min = min(value, self.min_stack[-1])
        else:
            current_min = value
        self.min_stack.append(current_min)

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

## 复杂度

- `push`、`pop`、`top`、`getMin` 的时间复杂度均为 O(1)。
- 空间复杂度：O(n)，需要两个栈保存 n 个元素。

## 踩坑点

- 栈必须保存为实例属性 `self.stack`，不能在 `__init__` 中写成局部变量 `stack`。
- `min_stack` 不能只保存出现过的最小值，否则弹出最小值后无法恢复上一个最小值。
- `push` 和 `pop` 必须同步操作两个栈，始终保持长度一致。
- 不要用 `min = 0` 代替最小栈；这无法维护历史状态，还会覆盖 Python 内置函数名。
