# 最大子数组和

LeetCode 53。

## 题意

给定一个整数数组，找出一个具有最大和的连续子数组，返回其最大和。子数组至少包含一个元素。

## 我的思路

定义 `cur_max` 为以当前位置结尾的最大子数组和。遍历到 `nums[i]` 时：

- 如果继续前面的子数组更好，就取 `cur_max + nums[i]`。
- 如果从当前元素重新开始更好，就取 `nums[i]`。

因此 `cur_max = max(nums[i], cur_max + nums[i])`。同时维护 `global_max`，记录遍历到当前位置时出现过的最大值。

## 标准模板

```python
def maxSubArray(nums):
    cur_max = global_max = nums[0]

    for i in range(1, len(nums)):
        cur_max = max(nums[i], cur_max + nums[i])
        global_max = max(global_max, cur_max)

    return global_max
```

这就是 Kadane 算法，也可以理解为把动态规划状态压缩到一个变量中。

## 复杂度

- 时间复杂度 O(n)。
- 空间复杂度 O(1)。

## 踩坑点

- `cur_max` 必须表示“以当前元素结尾”，不能表示任意位置的最大值。
- `global_max` 要和 `cur_max` 同时更新，不能只返回最后一个 `cur_max`。
- 初始化不能写成 0，否则数组全为负数时会错误地返回 0。
- 题目要求连续子数组，因此不能把不连续的正数简单相加。
