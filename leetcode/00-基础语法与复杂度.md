# 基础语法与复杂度

## Python 常用语法

```python
for num in nums:      # 遍历列表中的元素
for i in range(n):    # 遍历下标 0 到 n - 1

mapping = {}          # 空字典
seen = set()          # 空集合

if key in mapping:    # 判断字典中是否存在 key
seen.add(num)         # 向集合添加元素
```

## 常见时间复杂度

| 写法 | 常见复杂度 |
| --- | --- |
| 单层遍历 | O(n) |
| 两层嵌套遍历 | O(n^2) |
| 哈希表查找 / 插入 | 平均 O(1) |
| 排序 | O(n log n) |

## 练习原则

先写出暴力解，再思考哪一步重复扫描了数据，尝试用哈希表、双指针或其他结构消除重复扫描。
