# 哈希表

## 什么时候想到它

遍历数组或字符串时，需要快速判断：

- 某个值是否出现过
- 某个值对应的下标是什么
- 某个字符出现了多少次
- 两组数据是否包含相同的元素或频次

哈希表常能将两层枚举的 O(n^2) 优化为一次遍历的 O(n)。

## 常用结构

### set：只记录是否出现过

```python
seen = set()

for num in nums:
    if num in seen:
        return True
    seen.add(num)

return False
```

适用题：存在重复元素。

### dict：记录值与下标

```python
mapping = {}

for i in range(len(nums)):
    need = target - nums[i]

    if need in mapping:
        return [mapping[need], i]

    mapping[nums[i]] = i
```

适用题：两数之和。

### dict：记录字符出现次数

```python
count = {}

for ch in s:
    if ch in count:
        count[ch] += 1
    else:
        count[ch] = 1
```

适用题：有效的字母异位词。

## 易错点

- 两数之和要先查 `need`，再存当前数字。
- `set` 只有值，没有下标。
- 字典访问写作 `count[key]`。
- 注意题目要求返回下标、布尔值，还是统计次数。
