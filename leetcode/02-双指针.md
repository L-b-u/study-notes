# 双指针

## 什么时候想到它

当题目要求在数组中原地完成处理，并让满足某种条件的元素集中到一侧时，可以考虑同向双指针。

常见场景：

- 将零、负数或不满足条件的元素移动到一侧
- 原地去重
- 将满足条件的元素按原相对顺序保留

## 同向双指针的角色

- `right`：扫描指针，依次检查每个元素。
- `left`：边界指针，指向下一个满足条件的元素应该放置的位置。

以移动零为例，在处理到 `right` 前，数组满足：

```text
[0, left)      已放好的非零元素
[left, right)  已经扫描过的零
[right, n)     尚未扫描的元素
```

当 `nums[right] != 0` 时，将它与 `nums[left]` 交换，然后让 `left` 右移一位。

## 模板：移动零

```python
class Solution(object):
    def moveZeroes(self, nums):
        left = 0

        for right in range(len(nums)):
            if nums[right] != 0:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
```

LeetCode 此题要求原地修改列表，因此不需要返回 `nums`。

## 过程示例

```text
nums = [0, 1, 0, 3, 12]

right = 1：交换下标 0、1 -> [1, 0, 0, 3, 12]，left = 1
right = 3：交换下标 1、3 -> [1, 3, 0, 0, 12]，left = 2
right = 4：交换下标 2、4 -> [1, 3, 12, 0, 0]，left = 3
```

## 易错点

- `left == right` 时交换自身是正常且正确的。
- 只有发现非零元素时才移动 `left`。
- 使用 Python 的并行赋值交换两个元素：`nums[left], nums[right] = nums[right], nums[left]`。

## 模板：有序数组去重

```python
slow = 0

for fast in range(1, len(nums)):
    if nums[slow] != nums[fast]:
        slow += 1
        nums[slow] = nums[fast]

return slow + 1
```

含义：`nums[0:slow + 1]` 始终是已经保留的、不重复的有序元素；`fast` 扫描剩余元素。

发现新的值时，先将 `slow` 右移，再将 `nums[fast]` **复制**到该位置。这里不需要交换，因为被覆盖的位置属于已经处理过的重复区间，后续不会再使用。

## 相向双指针

当数组有序，且需要在两端元素之间寻找满足某个条件的组合时，可以让两个指针从两端向中间移动。

- `left`：从数组开头向右移动。
- `right`：从数组末尾向左移动。

### 模板：有序数组两数之和

```python
left = 0
right = len(numbers) - 1

while left < right:
    current_sum = numbers[left] + numbers[right]

    if current_sum == target:
        return [left + 1, right + 1]
    elif current_sum < target:
        left += 1
    else:
        right -= 1
```

### 为什么可以移动指针

- 当前和小于目标：`right` 左移只会让和更小；应让 `left` 右移以增大和。当前 `left` 即使搭配最大的 `right` 都不够，因此可以淘汰。
- 当前和大于目标：`left` 右移只会让和更大；应让 `right` 左移以减小和。当前 `right` 即使搭配最小的 `left` 都太大，因此可以淘汰。

### 易错点

- 题目返回的下标从 1 开始，需要返回 `[left + 1, right + 1]`。
- 循环条件是 `left < right`，避免使用同一元素两次。
- 用 `current_sum` 保存当前和，可以避免重复书写表达式。

## 相向双指针：最大容器面积

面对“两条边界构成容器，求最大面积”的题目，面积由下面公式决定：

```text
面积 = (right - left) * min(height[left], height[right])
```

### 模板：盛最多水的容器

```python
left = 0
right = len(height) - 1
best = 0

while left < right:
    width = right - left
    container_height = min(height[left], height[right])
    best = max(best, width * container_height)

    if height[left] < height[right]:
        left += 1
    else:
        right -= 1

return best
```

### 为什么移动短板

假设 `height[left] < height[right]`：

- 左边是当前容器的短板，决定容器高度上限。
- 若移动右侧长板，宽度必然变小，而左侧短板不变，容器高度最多仍是左侧的高度，面积不可能更大。
- 只有移动左侧短板，才可能找到更高的边界来提高容器高度。

因此每轮计算完面积后，移动较短的一侧；两侧等高时移动任意一侧都正确。
