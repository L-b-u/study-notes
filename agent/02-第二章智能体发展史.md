# 第二章：智能体发展史

参考资料：Datawhale `Hello-Agents` 第二章《智能体发展史》。

## 一、这一章要解决什么问题

现代 Agent 并不是突然出现的。它融合了几条长期发展的技术路线：

```text
符号主义：让机器能够表示知识、进行逻辑推理
联结主义：让机器从数据中学习模式
行为主义：让智能体通过和环境交互学习决策
预训练模型：让模型获得广泛知识和通用语言能力
LLM Agent：把模型、记忆、规划和工具组合成闭环系统
```

本章最重要的学习方法是看清楚“问题驱动的演进”：

```text
上一代方法的能力 → 暴露出新的瓶颈 → 下一代方法尝试解决
```

## 二、符号主义：知识加规则

### 1. 物理符号系统假说

符号主义认为，智能的本质是对符号进行表示、组合和逻辑操作。纽厄尔和西蒙提出的物理符号系统假说包含两个观点：

- **充分性论断**：任何物理符号系统，都具备产生通用智能行为的充分手段。
- **必要性论断**：任何能表现出通用智能的系统，其本质都必须是物理符号系统。

简单理解就是：

```text
智能 = 符号表示 + 符号操作 + 搜索 / 推理
```

早期 AI 因此把重点放在知识表示、逻辑规则和搜索算法上。

### 2. 专家系统

专家系统把特定领域专家的知识写入知识库，再由推理机根据事实和规则得出结论。

```text
用户事实 → 推理机匹配规则 → 新结论 / 行动
```

核心组成：

| 组件 | 作用 |
| --- | --- |
| 知识库 | 保存领域知识，常见形式是 `IF-THEN` 产生式规则 |
| 推理机 | 根据事实选择和执行规则 |
| 用户界面 | 收集输入并展示结论 |

两种基本推理方向：

- **正向链**：从已知事实出发，不断触发规则得到新结论，是数据驱动。
- **反向链**：从目标结论出发，反过来寻找需要满足的条件，是目标驱动。

MYCIN 是典型案例。它用大量医学规则辅助诊断，并通过置信因子处理医学判断中的不确定性。

### 3. 符号主义的优势和局限

优势：

- 推理过程清晰，可解释、可审计。
- 对规则明确的封闭领域效果好。
- 结论可以追溯到具体事实和规则。

局限：

- **知识获取瓶颈**：需要专家和知识工程师手工整理规则，成本高且难以规模化。
- **常识问题**：人类默认掌握的大量常识很难全部编码。
- **框架问题**：执行一个动作后，很难显式说明世界中哪些状态没有变化。
- **系统脆弱性**：遇到规则之外的新情况，系统可能完全失效。

这一组局限是理解后续学习范式的关键：不是规则不能推理，而是现实世界的知识太庞杂、模糊且变化太快。

## 三、SHRDLU：封闭世界中的综合智能

SHRDLU 工作在一个规则明确的“积木世界”中，用户可以用自然语言让它理解、规划并移动积木。

它集成了多个模块：

- 自然语言理解
- 世界状态表示
- 规划和动作执行
- 上下文记忆
- 对行为和原因的问答

SHRDLU 的重要意义是展示了一个完整的“理解—规划—行动—记忆”闭环。但它的成功高度依赖封闭环境：积木数量、规则和动作空间都有限。一旦离开积木世界，系统就缺少现实世界所需的常识和鲁棒性。

因此要区分：

```text
在封闭环境中表现好 ≠ 已经具备通用智能
```

## 四、ELIZA：规则也可以制造智能假象

ELIZA 是早期规则驱动聊天机器人的代表。它并不真正理解用户，而是通过关键词、模式匹配和文本替换生成回应。

基本流程：

```text
识别关键词 → 选择优先级最高的规则 → 分解输入 → 转换代词 → 重组回答
```

例如输入中出现 `I am ...`，程序可以匹配规则并生成类似“你为什么会……？”的反问。

ELIZA 说明了两件事：

1. 简单规则也能在有限场景中产生看似自然的对话。
2. 表面上的语言流畅不代表系统真的理解了语义。

规则聊天机器人在开放域中难以扩展，因为关键词、句式、上下文和例外组合会快速增加，规则库维护成本会出现组合爆炸。

## 五、从规则到学习

### 1. 联结主义

联结主义认为，智能不一定要被写成显式规则，也可以分布在神经网络参数中，通过数据学习输入和输出之间的模式。

```text
大量数据 → 神经网络训练 → 参数中形成隐式模式 → 对新输入进行预测
```

它擅长图像、语音、文本等非结构化数据，但缺点是解释性弱，训练需要大量数据和计算资源。

### 2. 强化学习

强化学习关注智能体如何通过和环境交互学会行动：

```text
状态 S_t → 策略选择行动 A_t → 环境返回奖励 R_{t+1} 和新状态 S_{t+1}
                         ↑_______________________________↓
                              根据反馈更新策略
```

核心概念：

- `State`：当前环境状态。
- `Action`：智能体可以采取的行动。
- `Policy`：根据状态选择行动的策略。
- `Reward`：环境对行动的即时反馈。
- `Return`：从当前时刻开始的累计奖励。

强化学习适合序贯决策，因为当前行动会影响未来状态，目标不是只获得当前奖励，而是最大化长期累计收益。

AlphaGo 的核心思路可以理解为：通过大量对局探索不同落子，依据胜负结果调整策略，并逐渐学会哪些局面和行动更有利于最终获胜。

### 3. 监督学习和强化学习的区别

| 对比项 | 监督学习 | 强化学习 |
| --- | --- | --- |
| 数据 | 输入和正确标签 | 状态、行动和奖励反馈 |
| 学习方式 | 模仿已有答案 | 试错并优化长期收益 |
| 目标 | 预测正确标签 | 学习最优策略 |
| 适合问题 | 分类、回归、识别 | 游戏、控制、规划、序贯决策 |
| 是否需要明确正确答案 | 需要 | 不一定，需要奖励信号 |

## 六、预训练：解决知识获取瓶颈的新方式

预训练—微调范式分为两步：

1. **预训练**：在海量文本上进行自监督学习，例如预测下一个词，让模型学习语言规律、事实知识和上下文模式。
2. **微调**：使用特定任务数据，让基础模型适应分类、问答、对话或其他任务。

```text
通用海量数据 → 预训练基础模型 → 少量任务数据微调 → 下游应用
```

预训练和专家系统的知识获取方式不同：

```text
专家系统：人类把知识显式写成规则
预训练模型：模型从海量数据中隐式学习统计规律
```

预训练缓解了人工逐条编码知识的瓶颈，但也带来新的问题：数据偏差、事实错误、知识过时、训练成本高和可解释性不足。

大模型规模达到一定程度后，可能表现出上下文学习和思维链推理等能力：不修改模型参数，只通过提示词和少量示例，就能完成新任务。

## 七、现代 LLM Agent 的组成

现代 LLM Agent 把历史上的多种思想组合起来：

| 模块 | 作用 | 历史来源或对应思想 |
| --- | --- | --- |
| LLM | 理解语言、推理、生成计划 | 联结主义、预训练 |
| 记忆 | 保存历史观察和任务状态 | 状态模型、上下文记忆 |
| 规划 | 拆解目标、决定行动顺序 | 符号规划、目标导向 |
| 工具 | 访问外部环境和执行操作 | 执行器、环境交互 |
| 反思 / 自我批评 | 根据结果修正计划 | 学习与反馈 |
| 执行模块 | 解析工具调用并真正执行 | 传统程序控制 |

其基本循环是：

```text
感知环境
   ↓
LLM 结合记忆进行思考和规划
   ↓
选择工具并执行行动
   ↓
获得工具结果和新的环境状态
   ↓
更新记忆，进入下一轮循环
```

你正在学习的 `first_agent` 是这个架构的最小版本：

- `llm_client.py`：LLM 决策核心。
- `prompts.py`：规定思考和行动协议。
- `tools.py`：提供外部工具。
- `agent.py`：执行循环、解析行动、记录 Observation。
- `prompt_history`：最基础的短期记忆。

## 八、发展史的主线

把本章压缩成一条技术演进链：

```text
符号主义
  ↓ 规则难以覆盖现实世界
联结主义
  ↓ 神经网络能学模式，但缺少明确决策和长期目标
强化学习
  ↓ 能通过交互学策略，但训练成本高、缺少广泛先验知识
预训练模型
  ↓ 获得通用语言和世界知识，但不能直接行动
LLM Agent
  ↓ 将模型、记忆、规划、工具和环境交互组合起来
```

这不是简单的“新技术完全替代旧技术”。现代 Agent 仍然在使用旧思想：工具调用是结构化行动，规划受到符号主义影响，强化学习提供反馈学习思想，神经网络提供感知和语言能力。

5. 预训练—微调让模型从海量数据中获得通用能力。

## 十、复习检查点与答案

### 1. 为什么说每一代智能体范式都是在解决上一代的瓶颈？

符号主义能够解释和推理，但知识需要人工编码，难以覆盖现实世界；联结主义让模型从数据中学习，减少手写规则，但不擅长长期决策；强化学习能通过交互学习策略，却需要大量任务反馈，且缺乏通用先验知识；预训练模型获得广泛知识，但自身不能直接访问环境和执行行动。

现代 LLM Agent 因此把多种能力组合起来，用模型负责理解和推理，用工具连接环境，用循环和记忆完成连续任务。

### 2. 专家系统的知识库和推理机分别做什么？

知识库存储领域事实和规则，例如 `IF 发烧 AND 咳嗽 THEN 可能感染呼吸道`。推理机接收用户事实，匹配适用规则并推出新结论。

正向链从事实出发逐步推导目标，反向链从目标出发寻找所需条件。MYCIN 主要采用目标驱动的反向推理，并用置信因子表示不确定性。

### 3. 为什么 SHRDLU 的成功不能说明它已经具备通用智能？

SHRDLU 运行在状态、动作和规则都比较明确的积木世界中，环境范围有限，系统可以为这个小世界建立相对完整的模型。离开这个环境后，它没有足够的常识、知识和鲁棒性处理开放世界，因此它展示的是封闭环境中的综合能力，而不是任意环境中的通用能力。

### 4. ELIZA 为什么看起来像是在理解用户？

ELIZA 会识别关键词，匹配句式，把用户输入中的一部分代入预先写好的回答模板，并进行简单的代词转换。它通过语言形式制造了连贯和共情的表象，但没有真正建立用户意图、事实和世界状态的语义模型。

### 5. 强化学习为什么适合序贯决策？

序贯决策中，当前行动会改变未来状态，当前收益也不一定等于最终收益。强化学习通过状态、行动、奖励和策略的循环，优化从当前时刻开始的累计回报，因此能够学习“现在暂时吃亏、未来获得更大收益”的策略。

### 6. 预训练如何缓解符号主义的知识获取瓶颈？

符号主义需要专家手工把知识写成规则，成本高且难以表达隐性常识。预训练使用海量文本进行自监督学习，让模型自动从数据中形成隐式的语言规律和世界知识，不需要逐条人工编码。

但预训练并没有彻底解决知识问题：数据可能有偏差或错误，知识会过时，模型的内部知识也不容易解释和精确修改。

### 7. 现代 LLM Agent 中哪些部分体现了历史上的不同思想？

- LLM 的神经网络和预训练知识体现联结主义。
- 工具参数、结构化计划和执行规则体现符号主义。
- 根据环境反馈反复调整行动，体现强化学习和行为主义的思想。
- 记忆、规划、工具调用和执行循环共同形成现代 Agent 架构。

### 8. 如果让 Agent 审查代码，三个时代分别会怎么做？

- 符号主义时代：使用语法规则、静态检查规则和人工编写的缺陷模式，优点是可解释，缺点是难以理解复杂语义。
- 深度学习但没有 LLM 的时代：使用标注过的代码缺陷数据训练分类或预测模型，能够发现统计模式，但需要大量高质量数据。
- LLM Agent 时代：让 LLM 理解代码和需求，结合 AST、静态分析器、测试工具和仓库检索，形成“分析—调用工具—验证—生成建议”的循环。

### 9. 为什么现代 Agent 仍然需要规则和 Workflow？

LLM 擅长开放式理解和规划，但可能产生幻觉、格式错误和不稳定决策。规则和 Workflow 可以约束权限、参数、审批和高风险操作，保证关键流程可控。因此现代系统通常让 Agent 处理开放问题，让确定性的代码负责边界和执行。

## 一句话总结

```text
智能体的发展史，就是从手工写规则，到从数据中学习，再到把模型、记忆、规划、工具和环境反馈组合成自主闭环的过程。
```
